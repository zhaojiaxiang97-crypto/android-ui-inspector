# tester-army/e2e 安卓真机实验

独立实验，不进入 Electron 安装包，不改现有 SDK/CLI/MCP。固定 `e2e 0.18.0`、`@e2e-dev/mobile 0.10.0`（内部 `agent-device 0.21.22`）；Node 22.22.3+（22.x）或24.8+。

两个入口隔离：默认配置只测试 `com.androiduiinspector.sample`，重开样例 dynamic 模式，点击一次并验证文字变化；`e2e.kuaishou.config.ts` 只测试用户已打开的快手设置页，一次进入播放设置，标题确认后返回。业务用例不调用 `app.open`、restart 或 clearState；引擎准备仅将已有 App 带到前台。无模型、无截图上传、无账号登录、无业务 App 安装/重启/清数据。输入后不重试，失败退出；停止 runner 不等于远端命令已经取消。

## 运行

这是独立 npm 子项目，根 TypeScript 构建排除这个目录，不要求生产安装下载测试框架。`npm run check` 离线验证配置拒绝与用例发现，`npm test` 才操作手机。手机名称只是上游选择条件，不是安全隔离；运行前必须确认该名称唯一。本实验不复用桌面调试授权，手机操作由本次明确授权和 ADB 提供。

先确认 USB 调试与真机授权。控件读取需要独立的 `com.callstack.agentdevice.snapshothelper` 助手；安装前需取得手机用户许可。只从锁定依赖自带的 APK 安装，核对其 manifest SHA-256；如已有不同签名助手，停止，不自动卸载。

```sh
cd scripts/experiments/tester-e2e
npm ci --ignore-scripts --no-audit --no-fund
npm run check
E2E_TELEMETRY_DISABLED=1 npx agent-device devices --platform android --json
```

确认列表只有一台名称匹配的手机。`E2E_DEVICE_NAME` 必须是该名称，不能填 adb 序列号；同名手机不运行。将下面的示例名称替换为实际名称，再明确确认本次操作：

```sh
E2E_TELEMETRY_DISABLED=1 E2E_DEVICE_NAME='QA Android' E2E_SAMPLE_CONSENT=sample-only npm run list
E2E_TELEMETRY_DISABLED=1 E2E_DEVICE_NAME='QA Android' E2E_SAMPLE_CONSENT=sample-only npm test
```

一次只运行一个进程，固定单设备、单 worker、零重试。`.e2e/` 留在本地并忽略，不发布真实页面与日志。环境变量只是运行确认，不代替人类授权；缺确认或设备名称时，在初始化引擎前拒绝。

业务导航必须另获本次授权，用户先进入快手 App 内设置主页。只读取唯一标题和唯一“播放设置”入口；目标页断言失败即停，不盲目返回。下列输出目录须改为每轮新目录，保留旧报告：

```sh
E2E_TELEMETRY_DISABLED=1 E2E_DEVICE_NAME='QA Android' E2E_KUAISHOU_CONSENT=settings-playback-back-once npm test -- --config e2e.kuaishou.config.ts --output .e2e/kuaishou-new-run --reporter list
```

三张截图仅本地留证；框架会遮盖识别到的安全输入，不代表整页个人信息已完全脱敏，不得直接公开。前置截图失败则不点击；目标页可选截图失败仍执行已确认的一次返回，并保留截图失败步骤。业务配置不会发现样例，样例配置也不会发现业务用例。离线检查覆盖两套配置的缺字段拒绝、用例隔离及单次输入源码约束。

## 本地报告（不操作手机）

```sh
npm run check:report
npm run report -- .e2e/kuaishou-20261008-16ymIW/report.json
```

使用 Node 标准库读取已有 `report-1`，不加载 mobile 引擎、不连接设备、不读取登录凭据。每次在源报告旁创建新的 `summary-随机编号/`，包含 `index.html` 和 `index.json`，不会覆盖旧报告或复制截图。HTML可以用本机浏览器打开；目录保持原位置以保留相对图片链接。

报告展示每个用例的全部尝试、步骤/断言状态、耗时、源码行、错误、清理结果及截图关联。早期失败不因后续通过消失；配置阶段失败和无执行记录明确显示。原始报告摘要保留，截图在生成时核对大小/哈希及本地路径；缺失或不匹配不加载，未提供摘要标为未核验。截图核对不是像素正确性验收，也不保证文件后来未变化。

页面没有脚本、远端图片或外部字体。只加载目录内PNG头符合的截图，拒绝越界路径和目录外链接；截图和错误文字仍可能含个人信息，不公开、不自动脱敏。其他附件只留编号，不展开日志/视频。当前仅支持普通测试报告；串行组、探索和历史携带报告明确拒绝，不静默漏掉内容。步骤里的点击/返回次数不是设备实际输入次数，未知模型用量不填0。

8项报告回归覆盖成功/失败/多次尝试、无截图/未执行/配置失败、文本注入、坏格式/未知类型、越界/符号链接及附件完整性。已有两份实测报告已离线生成，源文件逐字不变；快手三张截图核对通过，样例报告明确无截图。本轮没有新真机测试。

## 在Inspector中查看

新版源码已提供“测试报告”按钮；macOS也可用“File → 查看测试报告…”。打开后点“导入索引…”，选择生成的`summary-*/index.json`，即可按用例、尝试和步骤查看。失败步骤默认选中，右侧显示源码行、错误、清理结果及关联截图；无截图或文件变化会明确提示，取消/坏文件不会清空旧报告。Tab可切换控件，Escape关闭面板。

必须保留summary、父目录的report.json和artifacts原位置。Inspector重新核对原报告和图片摘要，不加载HTML，不运行用例，不修改当前快照或调试授权。索引/原报告各8MiB、最多5000步骤；PNG最多加载100张、单图10MiB、总16MiB。2026-10-08已更新安装版，真实文件选择器导入旧报告成功；用户确认第6/10/14步截图正常变化。自动化观察不一致的原因仍未知，不当产品刷新故障。截图可能含个人信息，仍只留本地。

“本次尝试诊断摘要”已于2026-10-09交付安装版：定位首次异常、跳到异常前最近有效截图、提示缺图及收尾风险。只整理旧报告，断言超时不直接判定点击失败；不同尝试或后续截图不冒充异常前画面。35项相关回归及构建通过；真实窗口验证合成异常定位、证据跳转和关闭/重开，旧快手报告3/3图加载、最后截图跳转及第10/14步画面切换。没有新手机测试或模型调用。

## 已有真机结果与下一步

2026-10-08 实测：Android 14 USB 真机，一次尝试、一次文字点击通过，正文6019ms、准备5570ms、模型调用0，报告清理状态complete。报告在本地 `.e2e/report.json`；本版本mobile引擎不支持runner trace，虽然配置请求trace，实际截图/视频/trace附件0，只有步骤和断言，不当完整视觉留证。两次前置CLI配置错误（报告器组合、输出目录越界）均在手机操作前退出，记录保留；随后仅一次实际UI测试，没有失败重发。

同日业务导航实测通过：准备3.06秒，正文12.503秒，一次尝试、一次press、一次back，三张截图及标题“设置→播放设置→设置”断言通过，清理complete、模型调用0。报告在 `.e2e/kuaishou-20261008-16ymIW/report.json`，未覆盖样例报告；本轮专用主机daemon已正常停止。实际press坐标为(540,1325)，与旧流程失败记录一致，因此不能解释为“文字中心替代父中心修好了”。不同运行状态及输入实现尚未对照，不宣称旧导航根因解决。

本地索引、Inspector离线查看及报告摘要已交付。实时只读诊断已进入源码：独立折叠区，显式填写包名后单次采集、30秒停止、无输入/导航/重试；查看图像来源/缺图原因/几何及本地节点定位，不映射旧截图。757项全量及构建、合成界面通过；授权快手后端一次6.322秒、157节点/71图/0取图失败、身份及连接清理通过。本轮未运行e2e或更新安装桌面，不当实际桌面入口闭环；WebP透明度未知待离线补验，再另确认交付。

导入报告不触发手机采集或输入；当前页采集是新现场，截图坐标/语义节点不当真实绘制图层身份，不做通用适配层。此实验不是独立图层采集的替代品，也不是AI自然语言验收。`agent.act`另需选择模型及确认数据发送范围，不能自动借用用户的登录或API Key。
