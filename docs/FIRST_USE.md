# 第一次使用（Mac arm64）

完成这一页后，你会得到一份真实 Debug App 快照，能在桌面查看、保存后重开，并通过本地 CLI/MCP 只读查询。SDK 可增强树、属性和独立图层，其他可调试 App 也可走兼容采集路径；本页使用已带 SDK 的自有样例。

## 1. 打开桌面

已拿到核验过的 `.app`：按[交付说明](DELIVERY.md)确认版本和路径，再正常打开。源码运行：准备 Bun、Node.js 22+，在项目目录执行：

```sh
bun install --frozen-lockfile
bun run build
bun run start
```

使用普通配置启动，历史保存在本机。后续重开也使用同一 App 或同一源码启动方式。

## 2. 准备手机和 Debug 样例

安装 Android SDK Platform-Tools，手机开启 USB 调试，用数据线连接并确认“允许 USB 调试”。终端执行 `adb devices -l`，目标设备应显示 `device`；`unauthorized` 需先在手机确认授权。

手机已有仓库样例时直接打开；尚未安装时，准备 JDK 17+、Gradle 9.6+、Android Platform/Build Tools 36，配置 `JAVA_HOME` 和 `ANDROID_HOME`，在项目目录执行：

```sh
gradle -p android :sample-app:assembleDebug --console=plain
adb -s '<设备序列号>' install -r android/sample-app/build/outputs/apk/debug/sample-app-debug.apk
```

在手机打开 **Inspector SDK Sample**，保留默认蓝色卡片和 `RED CHILD` 页面。使用 Debug 包；安装被拒绝时先处理手机确认，签名冲突时不要直接卸载已有应用。SDK 接入和构建详情见[Android说明](../android/README.md)。

## 3. 采集并查看

首页应显示“设备已连接”。需要选设备时点“切换设备”；未发现时点“刷新设备”。手机停在样例页面，点击 **采集当前画面**，等待树和设备画面出现、采集按钮恢复。

桌面按钮执行深度采集。左侧是控件树，右侧是画布：

- 先点树中的 `RED CHILD`，再点 **2D**，核对截图上的选中框及右侧节点属性；看名称、类名和 `bounds`，未取得的值显示“—”。属性栏关闭后，可用顶部“属性面板”图标打开。
- 点 **3D 层级**；展开/收起树节点，观察对应图层，拖动画布旋转，滚轮缩放，点 **适应**恢复完整视野。选中节点后仍可看属性。

树存在不代表每层都有独立图。边框、缺图或警告按实际结果显示；遇到采集错误先读提示，确认当前是允许调试的 App，勿把旧画面当成新结果。

本轮真实画面：[2D 截图与节点属性](images/first-use-2d.png) · [3D 层级](images/first-use-3d.png)。

<a id="lookin-interactions"></a>

### 可选：悬停联动、连续动画与属性定位

- 指向树行或画布控件，另一侧同步高亮；树上显示直接父子引导线。悬停保留点击选中、展开、滚动和键盘焦点。搜索临时显示已折叠子层时，3D指向当前可见的父层；手动隐藏的图层不显示悬停强调。
- 3D展开/收起使用约220ms过渡，快速反向从当前画面接续；收起时等父层合成图准备好再交接，失败兜底最多1.2秒。重置视角可被拖动或缩放中断，2D/3D切换短暂淡入；系统开启“减少动态效果”时直接完成。
- 属性搜索显示具体属性及所属分组。点结果或按Enter，只在属性栏中定位并高亮约1.6秒；输入时保持焦点和滚动位置。显示前30项并报告总匹配数，“复制”保留完整字段值，包括首尾空白、0、false和空字符串。清除或Esc恢复原显隐与手动折叠。

树悬停只强调画面；测距仍使用画布指向的控件，已固定的测距对保留。换控件、快照、关闭面板或离开工作区会清理对应的旧定位与高亮。验证范围见[交互验收](CORE_ACCEPTANCE.md#lookin-interaction-acceptance)。

<a id="node-navigation"></a>

### 可选：沿父级路径定位控件

属性栏“关系”显示从根到当前控件的路径。点击父级名称，会选中该控件并在树中定位；完整名称、类型和节点ID可通过提示查看。深层路径保留根、父级和当前控件，“…”展开完整路径，列表最多占160px高度；Esc收起列表并返回展开按钮。

显式定位会清除控件树筛选，只展开所需祖先。目标在聚焦范围外时退出聚焦，保留手动隐藏；普通退出聚焦仍回到原滚动位置。采集或局部刷新期间禁用定位，换控件/快照后收起完整路径，旧目标不能进入新会话。定位仅使用已有树，不请求手机。结果见[路径导航验收](CORE_ACCEPTANCE.md#node-navigation-acceptance)。

<a id="quick-select"></a>

### 可选：选择折叠画面里的控件

在 **3D 层级**工具栏点 **选择内部控件**，再点一块已折叠且已有画面的父层。列表显示该分支里与点击位置匹配的名称、类型和路径，每页最多30项；指向候选只显示轮廓，点候选才展开所需祖先、选中并定位。搜索筛选会清除；缺图、隐藏、单层聚焦或无法可靠映射的变换会提示原因。

列表注明“按边界匹配”，重叠候选不代表真实像素或事件响应顺序。按Esc退出并回到工具按钮；窗口失焦、换快照、刷新或改变展开/隐藏/聚焦范围时清理临时状态。悬停不补图，确认后才沿用普通选中时的按需加载。结果见[迁移验收](CORE_ACCEPTANCE.md#lookin-migration-acceptance)。

<a id="layout-links"></a>

### 可选：从布局规则定位关联控件

属性栏 **布局 → 原生布局规则**中，能唯一确认的 RelativeLayout / ConstraintLayout 目标显示为按钮。点击后在树中选中并定位目标；ConstraintLayout 的 `parent` 定位实际父容器。每条规则保留完整原值，可以搜索和复制。

目标只按完整资源ID在同父直接子节点中匹配。缺失、重复ID、不完整ID或父布局类型无法确认时显示原因；偏置、角度、布尔值等仍按普通值显示。布局规则是采集记录，不据此判断约束是否已生效。操作使用已有树，不请求手机。结果见[迁移验收](CORE_ACCEPTANCE.md#lookin-migration-acceptance)。

<a id="structured-values"></a>

### 可选：查看分层业务信息（需新版 Debug SDK）

自有 App 可通过[SDK 显式登记](../android/README.md#business-debug-metadata)树形状态。属性栏 **业务信息**按层折叠，保留文字、数字、布尔值和null；可按真实路径（例如 `state/detail/request/loading`）搜索并定位，清除搜索后恢复手动折叠。字段复制保留完整树，叶值复制保留原值和首尾空白。

普通标量快照继续写文件v1，包含新版业务信息时写v2；新端读取两版，旧端会明确拒绝v2文件。设备需要接新版SDK并重新构建；桌面安装版已支持读取，手机样例是否有登记数据取决于其SDK版本。结果见[迁移验收](CORE_ACCEPTANCE.md#lookin-migration-acceptance)。

<a id="layer-appearance"></a>

### 可选：减少3D边框干扰

在“3D 层级”右侧的设置图标中关闭“普通轮廓”，可以隐藏已加载图层的普通边框和确认无画面的空容器轮廓。选中、悬停以及缺图轮廓仍显示；折叠分支自身为空时，仍保留未取得分支画面的轮廓。

“选中强调”有轻、中、强三档：轻档只显示边框，中/强档增加半透明强调，悬停比选中更轻。默认普通轮廓开启、轻档、自由旋转；设置自动保存到本机，换快照、切换2D/3D或重新打开仍保留。“恢复显示默认”重设轮廓、强调和旋转模式，不重设相机，也不改快照或导出图片。

左侧树按真实层级逐层缩进，不再把深层父子压到同一列。超出侧栏宽度时可横向滚动；选中或“定位选中”会自动露出控件名称，聚焦返回保留横向和纵向位置。

<a id="lookin-operation-details"></a>

### 可选：水平旋转、长文本阅读和右键复制

在 **3D 层级设置 → 旋转模式**中选择 **仅水平旋转**，拖动和方向键只改变水平角度，俯仰与侧倾保持为0。默认仍为自由旋转，选择保存在本机；切换保留缩放、平移、选中和固定测距。重置、视图切换及聚焦返回也遵守当前旋转模式。

属性栏里的较长文本、描述和字符串属性保留换行，超过阅读区域高度后在内部滚动。复制使用完整原值，保留首尾空白；短字段维持紧凑显示。属性搜索仍检索完整内容，并可定位到实际字段。

在控件树或画布上右键，可按当前节点实际数据复制 **文本、资源ID、完整类名、层级路径**。不存在的字段不显示复制项，复制结果沿用属性栏反馈。层级路径用于说明当前快照中的父子位置；它不是跨页面稳定的自动化定位器。取消菜单、切换快照或刷新后，旧菜单不会复制已经失效的节点。

范围和验证结果见[操作细节验收](CORE_ACCEPTANCE.md#lookin-operation-details-acceptance)。

<a id="pinned-measurement"></a>

### 可选：固定两个控件的测距

普通悬停只显示控件名称与类型，不自动显示测距线和数值。需要测距时，在“3D 层级”中先选中一层，再指向另一层。按 **M**，或移到工具栏点击 **固定测距**，显示并保留这两个控件的间距/内边距。鼠标离开、改选其他控件、旋转、平移或缩放后，标线与底部数值仍显示；数值使用原始外框像素，不包含3D展开层距。

按 **M**、**Esc** 或点 **解除固定** 释放。第一次Esc只解除固定，下一次沿用原来的退出聚焦/3D操作。换快照、切换2D，或其中一层被隐藏、折叠到父层级、移出聚焦范围、替换或改变外框时会清除；恢复显示不会恢复旧固定结果。固定结果只保留在本次查看中。

<a id="node-image-export"></a>

### 可选：导出或复制控件图片

选中控件，在属性栏的“画面”里选择图片范围，然后点击 **导出 PNG** 或 **复制图片**。自身图只输出已保存的独立位图，保留原尺寸和透明度，不包含子层、画布强调或外部透明度；PNG、WebP、JPEG统一输出为PNG。

“此分支（含子层）”优先输出已保存的原生整组图，并显示其采集时间；没有整组图时，用已保存的独立位图本地重建设备可见子层。此范围不受工作台折叠或手动隐藏影响。本地重建保留透明底，明确标记缺失图层，不能据此确认与原生整组图逐像素一致。

没有可用位图时显示原因并禁用输出；样式重建不当作采集图片，也不会裁整屏截图补图。导出不会额外请求手机。保存前校验实际格式、尺寸和可解码性；本地重建边长最多4096 px、总像素最多1600万，超限明确提示，不偷偷缩图。取消保存不产生成功提示；切换控件或快照会停止尚未提交的图片准备，并忽略旧操作的迟到反馈。

<a id="inspector-groups"></a>

### 可选：只显示常用属性分组

在属性栏搜索框旁点 **分组**，或进入“偏好设置 → 属性分组”。勾选显示类型、业务信息、关系、布局、交互、画面、原始属性；取消勾选立即隐藏，并保存在本机。换控件、换快照或重新打开后仍保留。默认全部显示；**恢复属性分组默认**只恢复这七组，不改其他设置。

搜索属性名称或值时，会临时显示并展开隐藏分组中的匹配项。清除搜索或在搜索框按Esc后，恢复显隐设置和原来的手动折叠状态。可以全部隐藏，属性栏会保留提示和设置入口；没有采集业务信息或SDK交互属性的控件，不会补造这两组。

隐藏只影响显示，完整节点复制、快照文件和历史仍保留原始数据与业务分组。设置不写入快照，也不会增加手机请求。本机保存失败会提示仅在本次窗口生效；坏格式、不支持的版本、超长配置或读取失败恢复为默认显示。

<a id="layer-demand"></a>

### 可选：大场景中的图层加载（新源码）

3D会先加载选中和视口内的图层；平移、旋转或缩放后，新进入视口的图层自动补图，无需额外设置。暂未加载时先显示外框。它只减少展示时的解码和分支补图，不缩减原有深度采集或完整树。

同一次采集中，展开再折叠、切换2D/3D会复用已取得的整组图；新采集或局部刷新后重新取得，失败不会自动反复请求。整组图保留自己的采集时间，可能与原快照不同帧。展开看自身、折叠看分支；隐藏子图层时排除含有它们的整组图，沿用本地重建与精度提示。离线快照只使用已保存图像，缺图保持缺图。

<a id="color-preview-aliases"></a>

### 可选：查看源色和设置颜色别名（新源码）

在属性栏的“画面”查看已返回的颜色：Android 自有 Debug App 点击“读取实时样式”可看背景源色/当前文字色；QML 的“采集与样式详情”可看背景源色/边框源色，已保存属性离线也可查看。色块使用棋盘底纹显示透明度，原 ARGB/RGBA 仍可查看和复制。它表示颜色属性，不替代渐变、边框启用状态或控件/祖先的透明度。

“原值”复制采集值；“Hex”复制 CSS `#RRGGBBAA`，透明度放末尾；“RGBA”保留原始透明度精度。Android 原值是 `#AARRGGBB`，透明度放最前。QML 透明度无法用 8 位 Hex 精确表达时标 `≈`，配置精确别名请复制 RGBA。缺失、无效或来源未知的颜色保留原文，不生成色块。

在“偏好设置 → 颜色别名”每行输入“颜色 = 别名”，点击“保存颜色别名”立即生效并保存在本机，例如：

```text
#0066FF = 品牌主色
rgba(0, 102, 255, 0.5) = 半透明主色
```

最多 32 项，别名最多 64 字；支持 CSS 六/八位 Hex 或数值 RGBA，精确匹配颜色和透明度，同色重复项会提示。属性搜索能找到别名、Hex 和 RGBA，清除后恢复原折叠状态。“清空别名”只清除输入，保存后移除。别名不写入快照，原始颜色始终保留；本机保存失败会明确提示。

<a id="initial-tree-collapse"></a>

### 可选：减少树中的内部层级（新源码）

在“偏好设置 → 默认折叠”，或左树底部设置图标的“默认折叠设置…”进入。默认全部展开；“初始显示层级”留空为不限，填5表示显示到第5层，根节点为第1层。“默认收起的类型”每行填写一个具体类名，例如`SvgView`或自有App的`com.example.LoadingView`。完整名精确匹配该类，短名匹配各包同名类；区分大小写，不匹配继承或通配符。最多32项，每项200字，层级1–200。

“保存设置”作用于下次采集或打开文件/历史，不改变当前树；“应用到当前树”立即重设展开状态，保留选中节点的路径。采集、刷新、筛选和聚焦时暂不能应用，结束后可用。“清空规则”只清除输入，再保存或应用即可恢复全部展开。

收起后仍保留完整节点、属性和图片。可手动展开、搜索或点击“定位”；搜索临时显示路径，清除后恢复，定位会展开选中路径。渐进采集/局部刷新保留已有分支的手动状态；新分支使用该轮规则。2D/3D仍为展开看自身、折叠看分支，离线缺图按原提示展示。

<a id="lookin-discovery"></a>

### 可选：继承图标、操作提示与图片预览

- 自定义控件有 SDK 继承信息时，树图标按最近的已知 Android 父类型显示。例如自定义文字控件显示文字图标，真实名称和类名仍保留；缺少可靠信息时沿用原来的判断。
- 首次使用快速选择、聚焦或固定测距时，画布上方出现一条操作提示。每个页面会话最多一条，点“知道了”或按 Esc 关闭后保存在本机；在“偏好设置 → 操作提示”可重置。采集、拖动和弹窗期间暂时隐藏并保留行高，画布不会因此跳动；退出对应操作时清除提示。
- 在属性栏“画面”里选择自身图或此分支，点 **预览图片**。窗口显示原始像素尺寸、来源和透明棋盘，支持适应、100% 与缩放；换控件、图片范围或会话会关闭旧预览。只使用已保存图片，不追加手机读取。图片弹窗中按 Esc 只关闭预览，原固定测距和 3D 保留。

结果见[本轮验收](CORE_ACCEPTANCE.md#lookin-discovery-acceptance)。

<a id="lookin-usability"></a>

### 可选：快捷展开、状态说明与二维测距

- 树上方选择 **前 2 层 / 前 4 层 / 全部**，只调整当前树。深层选中路径保持展开；聚焦时按当前分支计算，退出恢复原视图。筛选或采集期间暂时禁用，不修改默认折叠设置。
- 树行的 **已隐藏、不可见、等待、缺画面、自身空图、失败** 可查看详细说明，属性的“画面”组也能搜索。隐藏仅影响当前图层；自身空图不代表子层空白，缺图不代表透明。折叠整组图仍单独说明实际来源。
- 在 3D 中选中一层、指向另一层，点击 **固定测距** 或按 **M**，左下出现二维卡片，显示两控件的原始外框、间距和对齐关系。数值为屏幕 px，不包含 3D 展开距离。卡片避开属性栏，快速选择时暂时收起；用 **解除固定 / M / Esc** 关闭。配对失效或切回 2D 后清除，不重新读手机。

## 4. 保存，退出，再打开

选择 **文件 → 保存快照**（`⌘S`），再打开 **文件 → 快照与历史**，确认“已保存本地快照”和新记录。从屏幕顶部的 **Android UI Inspector** 菜单选择 **Quit**（`⌘Q`）退出，再正常打开桌面；在“快照与历史”选择刚保存的记录，核对树和设备画面。已有历史可离线查看；新采集需再次手动保存。

<a id="offline-snapshot-files"></a>

### 可选：保存为文件，离线打开（新源码）

需要含离线文件功能的新源码或独立预览版，原安装版尚未更新。选择 **文件 → 导出 → 导出完整快照…**，保存JSON文件；在另一窗口用 **文件 → 打开快照…**（`⌘O`/`Ctrl+O`），也可从首页“打开快照…”进入。无需连接手机，打开后可搜索控件、查看属性和已有的2D/3D图像，再用“保存快照”加入本机历史。

完整文件保留整屏、节点图、已取得的原生分支图、采集信息及缺图原因。旧“导出 JSON”仍只导出控件树；这种旧文件也能打开，但会提示未包含整屏截图。导出不会补采未取得的图片；已保存分支图显示原采集时间，本地重建仍明确标注。

文件最大100MiB，历史保存仍限单份50MiB；图片、节点和版本另有校验。取消或打开失败保留原页面。使用原生文件选择器时，先完成文件选择和系统权限确认，等待本地读取完成。

## 5. 只读共享这一份快照

保留刚打开的历史快照，选择 **文件 → MCP → 共享当前快照（只读）**。确认这是要共享的页面，在弹窗点 **共享这一份**。共享内容包括控件文本、属性和已采集图片；本机查看可直接使用 CLI。

CLI/MCP 需要 Node.js 22+。App 内置 CLI；将下例路径替换为实际 App 路径。源码运行时，`inspector_cli` 改为 `dist-electron/cli.cjs`。

```sh
inspector_cli='<实际 App 路径>/Contents/Resources/cli/android-ui.cjs'
node "$inspector_cli" snapshot --pretty
node "$inspector_cli" tree --snapshot '<返回的 snapshotId>' --depth 20 --pretty
node "$inspector_cli" attributes --snapshot '<同一 snapshotId>' --node '<tree 返回的节点 id>' --pretty
```

这些命令读取已共享数据，不重新采手机。桌面须保持运行，查询使用同一 `snapshotId`；静态只读共享直接查询即可。更多查询见[CLI说明](CLI.md#查看页面)。

上例使用普通配置。指定独立配置目录时，CLI 追加 `--snapshot-file '<配置目录绝对路径>/mcp/current.json'`；MCP 使用该窗口复制的配置，其中的共享文件路径应指向同一目录。

已有本地 MCP 客户端时，选择 **文件 → MCP → 复制 MCP 配置**，添加复制的配置并重连；依次调用 `get_snapshot`、`get_tree(snapshotId, depth=20)`、`get_node(snapshotId, nodeId)`，使用前一步返回的实际 ID。配置指向当前 App 自带的服务，读取同一份共享快照，接入方式见[MCP说明](MCP.md)。

## 6. 停止共享

选择 **文件 → MCP → 停止 MCP / 自动调试**，或点桌面 **立即停止**。再次运行 CLI `snapshot` 应提示未共享；保存的历史仍可查看。切换快照、重新采集或退出桌面也会撤销共享，客户端此前已收到的数据需由客户端管理。

本页流程已用候选 `first-use-20261011-a3e1636e` 在单台 Mac arm64、Android 14 上实测：独立空配置采集 15 节点，查看 2D/3D、保存并正常退出重开后，再共享同一真实快照给包内 CLI/MCP；停止共享后旧 ID 失效，历史保留。手机使用已安装的原样例 **0.1 / code 1**，本轮未重建或重装 Android；干净系统首次安装尚未验证。

## 7. 可选：完成一次固定样例任务

需要含固定任务接口的新源码或候选 `diagnosis-handoff-20261011-ab4c3840`；当前本机安装版 `de87a543` 尚未包含这两个接口。任务定义直接使用[自有样例文件](../tests/fixtures/sample-dynamic-task.json)，原始目标和验收条件不能在操作后改写。

先把第5步的 `inspector_cli` 改为含新接口App的包内CLI路径（源码构建用 `dist-electron/cli.cjs`）。下例在仓库根目录执行；只有App时，将上面的任务文件保存到本机，`--task-file`换为其绝对路径。独立配置每条CLI命令追加 `--snapshot-file '<该配置目录>/mcp/current.json'`。

1. 保持手机解锁、亮屏，重开**项目自有样例**的 dynamic 页面：

   ```sh
   adb -s '<设备序列号>' shell am start -S \
     -n com.androiduiinspector.sample/.MainActivity --es mode dynamic
   ```

   此命令会重开这个样例 Activity，使文字恢复 `RED CHILD`。再从桌面“开启自动调试…”核对包名并授权；执行 `node "$inspector_cli" attach --pretty`获取会话 `id`。CLI 使用该窗口的共享路径，MCP 使用该窗口复制的配置。

2. CLI 定义任务，MCP 检查初始阶段：

   ```sh
   node "$inspector_cli" task-define --session '<会话ID>' --task-file tests/fixtures/sample-dynamic-task.json
   ```

   保留定义返回的 `taskId`，调用 `check_debug_task(sessionId, taskId, checkpointId="ready")`。通过后，用其第二次观察的 `snapshotId` 查询精确文本 `RED CHILD` 和类名 `android.widget.TextView`，确认仅一个节点且 `clickable/enabled=true`。

3. 使用这个快照和节点，CLI 只点击一次：

   ```sh
   node "$inspector_cli" tap --session '<会话ID>' --snapshot '<第二次观察ID>' --node '<精确节点ID>' --target self
   ```

   随即调用 MCP `check_debug_task(sessionId, taskId)`。两次新观察均须满足：`UPDATED CHILD`、`NEW VIEW` 可见，`RED CHILD` 消失。`sent` 回执不能代替验收；未通过时停止并保留记录，手动恢复页面后重新开会话。

4. 停止前运行 `node "$inspector_cli" attach`保留返回的 `reportPath`；执行 `node "$inspector_cli" stop --session '<会话ID>'` 后，在桌面“自动调试 → 查看调试记录”查看四步及六次观察。正常退出重开，从“测试报告 → 导入报告…”选择该 `reportPath`，保留原目录 `artifacts/`；核对原始目标、最终条件和两张历史截图。导入只读，不恢复授权或操作手机。

此组合已用上述独立候选在单台 Mac arm64/Android 14 实测通过，成功轮只有一次样例点击；先前被系统丢弃输入的失败轮另行保留。重开导入成功、失败记录均与原树和截图一致，详见[验收](CORE_ACCEPTANCE.md#task-sample-flow-acceptance)。
