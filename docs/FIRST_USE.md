# 第一次使用（Mac arm64）

完成这一页后，你会得到一份真实 Debug App 快照，能在桌面查看、保存后重开，并通过本地 CLI/MCP 只读查询。当前源码默认标准采集，无需接入 SDK；有需要再显式开启增强。本页保留自有样例的操作示例，安装版能力以[交付说明](DELIVERY.md)为准。

## 1. 打开桌面

已拿到核验过的 `.app`：按[交付说明](DELIVERY.md)确认版本和路径，再正常打开。源码运行：准备 Bun、Node.js 22+，在项目目录执行：

```sh
bun install --frozen-lockfile
bun run build
bun run start
```

使用普通配置启动，历史保存在本机。后续重开也使用同一 App 或同一源码启动方式。

### 工作台的操作位置

- 窗口顶部：选择设备、采集快照、快照历史、属性面板和更多工具。
- 画布上方：2D / 3D、缩放、适应画布、测距、选择图层和 3D 设置。点击百分比可选常用倍率、连续缩放或重置视图。
- 属性栏：先显示选中控件及对比入口；搜索框旁的“显示设置”集中管理颜色格式和分组。


## 2. 准备手机和 Debug App

安装 Android SDK Platform-Tools，手机开启 USB 调试，用数据线连接并确认“允许 USB 调试”。终端执行 `adb devices -l`，目标设备应显示 `device`；`unauthorized` 需先在手机确认授权。

直接打开允许调试的 App 即可使用标准采集，不要求修改 App。若需要跟随下方固定页面示例，可使用仓库自有样例；尚未安装样例时，准备 JDK 17+、Gradle 9.6+、Android Platform 30 和 36、Build Tools 36，配置 `JAVA_HOME` 和 `ANDROID_HOME`，在项目目录执行：

```sh
gradle -p android :sample-app:assembleDebug --console=plain
adb -s '<设备序列号>' install -r android/sample-app/build/outputs/apk/debug/sample-app-debug.apk
```

在手机打开 **Inspector SDK Sample**，保留默认蓝色卡片和 `RED CHILD` 页面。样例带有 SDK，但桌面标准模式不会探测或使用它。使用 Debug 包；安装被拒绝时先处理手机确认，签名冲突时不要直接卸载已有应用。SDK 接入和构建详情见[Android说明](../android/README.md)。

## 3. 采集并查看

首页应显示“设备已连接”。需要选设备时点“切换设备”；未发现时点“刷新设备”。手机停在要检查的页面，点击 **采集当前画面**，等待树和设备画面出现、采集按钮恢复。

标准模式的桌面主按钮先读取完整 Debug 控件树和截图，默认以 2D 展示。选中或展开控件时，再读取该分支的独立图层，每次最多 32 层；较大分支可继续点 **读取当前分支**，失败时可重试。未读取的图层标为 **待加载**，不作为空层或失败层处理。

在实时快速快照中点击 **3D 层级**，会自动读取完整图层。等待时保留 2D；新截图尚未到达时，单独显示并标注上次截图，不把旧图绑定到新控件树。取得可用独立图后进入 3D；如果用户主动选择 2D，完成后继续保持 2D。全部取图失败时也保持 2D，并保留失败说明。

也可点画布提示栏的 **完整采集**，或 **更多工具 → 完整采集所有图层**。待加载节点默认不绘制、不占层距；已采集的子层仍可显示。需要看布局边界时，可在 **3D 设置**中开启空图层并选择完整结构；这不代表独立图片已读取。SDK 增强、Qt/QML 和自动调试仍保持原采集方式；标准路径不回退为 UIAutomator。左侧是控件树，右侧是画布：

- 先点树中的可见文字控件（样例为 `RED CHILD`），再点 **2D**，核对截图上的选中框及右侧节点属性；看名称、类名和 `bounds`，未取得的值显示“—”。属性栏关闭后，可用顶部“属性面板”图标打开。
- 点 **3D 层级**；展开/收起树节点，观察对应图层，拖动画布旋转，滚轮缩放，点 **适应画布**恢复完整视野。选中节点后仍可看属性。
- **3D 画布下方**提供“正视、层叠、展开”、层距滑杆和“完整结构”。默认隐藏空层；点击“完整结构”临时显示透明容器边框并恢复完整层距，再点一次恢复原设置，切换快照不会丢失原偏好。拖偏后点“层叠”回到清晰视角；“展开”拉开间距，同时保留页面可读性。三个视角都会自动适应画布，保留选中控件、树的展开状态和显示偏好。细轮廓随缩放保持清晰，选中层使用蓝色边框；仍可手动旋转，在 3D 设置中精确输入层距和视距。

树存在不代表每层都有独立图。快速快照只保存已读取的图片；历史和导入快照离线查看，不会自动连接手机补图。补图读取的是手机当前画面，若窗口、控件身份或位置已变化，会要求重新采集；不保证动态图片与原截图同帧。边框、缺图或警告按实际结果显示。

此前样例实测画面：[2D 截图与节点属性](images/first-use-2d.png) · [3D 层级](images/first-use-3d.png)。它们不代表本轮标准模式的真机验收。

### 查看文字样式（无需 SDK）

重新采集后选中文字控件，在 **画面 → 文字样式** 查看系统实际返回的字号、粗斜体、当前文字颜色、文字对齐、方向和省略方式。可搜索“字号 / textSize”“粗体 / typeface”等关键词并复制值。样式随控件树一起读取，不增加设备请求；保存快照后仍可离线查看，旧快照需重新采集才有新增字段。

字号使用原始 **px**，粗斜体不等于数值字重。字段依据 [Android TextView 导出实现](https://github.com/aosp-mirror/platform_frameworks_base/blob/android-14.0.0_r1/core/java/android/widget/TextView.java#L15481-L15494)，按实际返回显示，不推测缺失值。

需要进一步检查字体时，点击同一区域的 **读取字体**。它通过 Debug 连接单独读取当前文字画笔使用的基础字体，显示系统家族名称、实际数值字重、样式、斜体及默认字体回退标记，标准模式和 SDK 增强模式均可用，不要求 SDK。Android 14 起提供系统家族名称接口；系统未返回名称时显示“未提供名称”，旧系统缺少接口时会单独说明。不能由此断定自定义字体名称，也不代表具体字体文件或每个字符的回退字体。

字体按钮读取手机的实时状态，显示读取时间，不写入历史快照；切换控件或快照会清除结果。历史快照不连接设备读取字体，当前非 TextView 控件会给出提示。窗口、进程或控件已变化时需要重新采集。字间距、行距和富文本逐段样式暂未接入。SDK 的“读取实时样式”仍是另一项显式操作，不会覆盖快照属性。

<a id="sdk-enhancement"></a>

### 可选：启用 SDK 增强（新源码）

在 **偏好设置 → 采集 → 启用 SDK 增强** 中开启，适用于已接入本项目 SDK 的 Debug App。默认关闭，旧配置缺少此项时也使用标准模式；App 已安装 SDK 不会自动开启增强。设置由桌面主进程保存在本机。

- 标准模式不探测 SDK 声明、不建立 SDK 会话；增强模式可增加树、属性、独立图和显式登记的业务信息。SDK 不可用时保留基础采集，缺图继续标明原因，不保证任意 App 的精确画面。
- 采集、刷新、诊断或自动调试忙碌时不能切换。切换保留已有快照和图片，但旧实时会话失效；重新采集后才能继续补图、局部刷新等实时操作。
- 历史和导入快照仍可直接查看，已有 SDK 数据不会被删除。桌面自动调试的深度观察沿用当前模式；CLI/MCP 默认标准模式，只能沿用桌面授权会话，不能用单次请求开启增强。轻量观察的 UIAutomator／可选 Helper 路径保持不变。

接入见[Android说明](../android/README.md)，实现见[SDK 可选化记录](SDK_OPTIONAL_ENHANCEMENT_PLAN.md)。当前源码已通过无 SDK 样例与原生桌面流程检查，具体边界见[本轮验收](CORE_ACCEPTANCE.md#sdk-optional-acceptance)；桌面安装版尚未更新。

<a id="lookin-interactions"></a>

### 可选：悬停联动、连续动画与属性定位

- 指向树行或画布控件，另一侧同步高亮；树上显示直接父子引导线。悬停保留点击选中、展开、滚动和键盘焦点。搜索临时显示已折叠子层时，3D指向当前可见的父层；手动隐藏的图层不显示悬停强调。
- 3D展开/收起使用约220ms过渡，快速反向从当前画面接续；收起时等父层合成图准备好再交接，失败兜底最多1.2秒。重置视角可被拖动或缩放中断，2D/3D切换短暂淡入；系统开启“减少动态效果”时直接完成。
- 属性搜索显示具体属性及所属分组。点结果或按Enter，只在属性栏中定位并高亮约1.6秒；输入时保持焦点和滚动位置。显示前30项并报告总匹配数，“复制”保留完整字段值，包括首尾空白、0、false和空字符串。清除或Esc恢复原显隐与手动折叠。

普通树悬停只强调画面；测距模式下，树与画布的悬停都可选取比较对象，已固定的测距对保留。换控件、快照、关闭面板或离开工作区会清理对应的旧定位与高亮。验证范围见[交互验收](archive/ACCEPTANCE_HISTORY_2026-10-15.md#lookin-interaction-acceptance)。

<a id="tree-row-mode"></a>

### 可选：详细显示树行（新源码）

控件树上方点 **紧凑 / 详细** 切换行模式。详细行第二行优先显示已有资源 ID，没有 ID时显示类型；长 ID保留尾部，完整值仍可通过提示和复制读取。模式保存在本机，切换保留当前阅读控件、选中和展开状态。

<a id="viewing-scope"></a>

### 可选：确认当前查看范围（新源码）

树上方集中显示聚焦分支、文字筛选、可交互、有标识和手动隐藏。点各条件的 **×** 单独退出，点 **恢复完整查看** 一起清除；原折叠状态和不可见边界开关保留。这些操作只改变当前快照的查看范围，不重新采集。

<a id="single-layer-restore"></a>

### 可选：只恢复一个隐藏图层（新源码）

在树中右键手动隐藏的节点，选择 **恢复此图层**；其他隐藏项保留。父层仍隐藏时，会显示原因，可点 **定位隐藏的父层** 再处理。恢复仅改变桌面展示，设备不可见或缺图仍按实际数据显示；恢复全部入口继续可用。

<a id="branch-expansion"></a>

### 可选：整理当前分支（新源码）

在树或画布右键有子层的控件，选择 **展开此分支** 或 **收起子层**。收起子层保留当前控件展开，让直接子控件仍可见；分支外的状态和当前选中路径保留。筛选或采集期间暂时禁用，不改变默认折叠规则。

<a id="workspace-layout"></a>

### 可选：记住工作区布局（新源码）

拖动树与画布间的分隔线调整树宽。属性栏可停靠或浮动，浮动后拖动标题移动，拖动右下角手柄调整大小；手柄支持方向键，Shift加大步长，Home恢复默认尺寸。树宽、浮动位置/大小和停靠选择自动保存在本机。

窗口变小时会临时限制面板在可见区域，放大后恢复原偏好。需要重新安排时，点 **偏好设置 → 工作区布局 → 恢复默认布局**。从报告定位属性会临时停靠，偏好中显示的仍是已保存设置；保存失败会明确提示。

<a id="continuous-zoom"></a>

### 可选：连续调整画布倍率（新源码）

点击画布上方的倍率（如 **100%**），拖动滑杆调整25%–1600%，方向键微调，Esc收起。2D围绕可见画布中心缩放，3D保留当前旋转和平移；固定 A/B和原始 px距离保持不变。原滚轮、倍率预设、加减和适应继续可用。

<a id="color-format"></a>

### 可选：切换颜色显示格式（新源码）

在 **偏好设置 → 颜色显示** 或属性栏 **显示设置 → 颜色格式** 中选择 Hex、RGBA或原值，立即生效并保存在本机；默认 Hex。复制按钮标明格式，其他格式与原值收进详情；透明度、近似提示和精确别名保持原语义，来源不明仍显示原文。详见[颜色说明](#color-preview-aliases)。

<a id="node-reference"></a>

### 可选：固定一份属性作参考（新源码）

选中 A，在属性栏点 **设为对比参考**，再选 B。参考卡保留 A已有的名称、位置/尺寸、文本和颜色；点卡片标题展开，点 **更新对比参考** 替换，点 **×** 关闭。最多一份，只使用已有数据，卡片标明快照、采集时间和来源。

局部刷新后卡片提示固定时的旧值；原控件身份无法确认时也明确提示，不跟随到新控件。换快照清除，测距期间与属性栏一起避让。焦点在参考卡内时，Esc关闭并回到固定按钮。结果见[第二轮验收](archive/ACCEPTANCE_HISTORY_2026-10-15.md#lookin-ui-round2-acceptance)。

<a id="tree-search-suggestions"></a>

### 可选：从搜索建议找到控件

树搜索会列出当前快照已有的文本、资源 ID 和类型，最多8项。上下键预选，Enter 采用，Esc 先关闭建议、再次按下清空筛选；中文输入法确认不会误选建议。清空后恢复原展开和滚动位置，显式定位则以目标位置为准。大树只限制建议扫描量，原树筛选仍检查完整数据。

<a id="search-match-navigation"></a>

### 可选：逐个查看搜索匹配（新源码）

筛选后，搜索区显示匹配总数和当前序号。点 **上一个匹配 / 下一个匹配** 连续查看，首尾循环；祖先路径不计入数量。焦点在树或树搜索框时，用 **Cmd/Ctrl＋G** 向后巡览，加 **Shift** 向前。尚未选中匹配时，两种方向都从首个开始；中文输入法和建议列表的 Enter优先保持原行为。

<a id="node-visit-history"></a>

### 可选：返回刚才查看的控件

控件树上方的左右箭头用于 **上一个查看控件 / 下一个查看控件**，最多保留当前快照内50次查看。明确选中或沿关系跳转才记录；悬停和搜索建议预选不会记录。返回时恢复树和属性栏的阅读位置；筛选或聚焦范围已变化时，先确保目标可见。

后退后另选控件，会从这里开始新的查看分支。换快照清空；局部刷新只保留身份仍能确认的记录，采集和刷新期间暂不可用。这两个按钮仅用于检查工具，不向手机发送返回或前进操作。

<a id="workbench-appearance"></a>

### 可选：切换界面外观

在 **偏好设置 → 外观**选择深色、浅色或跟随系统，立即生效并保存在本机；首次仍为深色。工具栏、控件树、属性栏及弹窗随设置切换，检查画布保持深灰，截图原色、选中控件和测距配对保持不变。

<a id="node-navigation"></a>

### 可选：沿父级路径定位控件

属性栏“关系”显示从根到当前控件的路径。点击父级名称，会选中该控件并在树中定位；完整名称、类型和节点ID可通过提示查看。深层路径保留根、父级和当前控件，“…”展开完整路径，列表最多占160px高度；Esc收起列表并返回展开按钮。

显式定位会清除控件树筛选，只展开所需祖先。目标在聚焦范围外时退出聚焦，保留手动隐藏；普通退出聚焦仍回到原滚动位置。采集或局部刷新期间禁用定位，换控件/快照后收起完整路径，旧目标不能进入新会话。定位仅使用已有树，不请求手机。结果见[路径导航验收](archive/ACCEPTANCE_HISTORY_2026-10-15.md#node-navigation-acceptance)。

<a id="quick-select"></a>

### 可选：查看重叠图层与折叠内部控件

**普通点击**会穿过已确认透明的像素，优先选择有实际画面的控件；半透明遮罩仍可选。确认没有自身画面的空图层默认不显示，也不占层距；有画面的子控件和折叠后有内容的整组画面仍然保留。层级树保留全部节点，选中空图层时会提示如何显示边界。缺图或读取失败不当作空图层。

**双击展开**会自动穿过没有自身画面的中间容器，在每个分支的第一层有画面控件处停下，不会一次展开所有子层。树行与画布双击行为一致；采集失败、画面未知或设备不可见的分支不会被自动跳过。树上的展开箭头仍逐层展开，默认再次双击收起；“双击聚焦分支”偏好保持聚焦行为。

在 **3D 设置 → 显示空图层** 中可恢复空图层，设置会自动保存。开启后默认紧凑排列；需要逐层检查时，再选择 **结构展示 → 完整结构（逐层展开）**。空图层边界受“普通轮廓”开关控制。手动隐藏仍然独立生效，开启显示空图层不会恢复手动隐藏的节点。

真实图层按遮挡关系排列在等距的深度层上，同组件内也使用相同层距；互不遮挡的内容可以共用一层。侧视时保持细轮廓可见，选中后用蓝色边框定位。这里的层距用于查看结构，不是设备上的原生高度。

**选择图层 → 此位置的图层**会列出当前画布上覆盖点击位置的图层；开启“显示空图层”后也包括空容器。有画面的候选优先，标签区分“此处透明”“无自身画面”“画面未确认”。悬停或键盘聚焦候选预览完整边界，点击后定位到树里的对应控件。隐藏的图层不会列入。

<a id="pinned-measurement"></a>

### 可选：指定两个控件，测量距离

1. 在 **2D 截图或 3D 层级**中，从树或画布选中控件 **A**。
2. 点工具栏 **测距**，再将鼠标移到树或画布中的控件 **B**；无需点击 B。
3. 右侧属性栏切换成测距结果，显示两张已保存控件图片及距离。水平用蓝色、垂直用橙色；包含和部分重叠时也会比较对应边缘，不把重叠一律当成 0。

按住 **Option / Alt** 可以临时测距，松开后结束；临时面板中的复选框可让模式继续保持。想保留当前结果，点 **固定这对控件** 或按 **M**。固定后，改选、悬停、旋转、平移和缩放均不会改动 A/B；点 **继续悬停测距** 可恢复实时比较。

没有选择时，面板先提示选择 A。点 A/B 旁边的 **选择 / 重选** 可以明确指定其中一端，再从树或画布点击目标；也可点 **使用当前选中控件**。两端不能是同一个控件。

数值采用原始外框的屏幕 px，不包含 3D 展开层距。图片只读取已保存原生分支图或本地重建图，缺图会说明，仍可测量外框。主画布不显示测距标签、连接线或端点；未开启测距时，普通悬停只显示控件身份。

**Esc** 或 **结束测距** 关闭面板并恢复属性栏；固定结果也可按 **M** 结束。同一快照内切换 2D / 3D 保留配对；换快照、隐藏或失效端点会清除旧配对。结果只保留在本次查看中。

点 **复制结果**，可复制 A/B 名称、比较边缘、px 数值和已知的快照标识、采集时间。离线导入没有采集时间时明确标为未知。底部状态栏显示当前操作；完整快捷键在工具栏 **帮助** 中查看。

<a id="color-preview-aliases"></a>

### 可选：查看源色和设置颜色别名（新源码）

在属性栏的“画面”查看已返回的颜色：Android 自有 Debug App 点击“读取实时样式”可看背景源色/当前文字色；QML 的“采集与样式详情”可看背景源色/边框源色，已保存属性离线也可查看。色块使用棋盘底纹显示透明度，原 ARGB/RGBA 仍可查看和复制。它表示颜色属性，不替代渐变、边框启用状态或控件/祖先的透明度。

“原值”复制采集值；“Hex”复制 CSS `#RRGGBBAA`，透明度放末尾；“RGBA”保留原始透明度精度。Android 原值是 `#AARRGGBB`，透明度放最前。QML 透明度无法用 8 位 Hex 精确表达时标 `≈`，配置精确别名请复制 RGBA。缺失、无效或来源未知的颜色保留原文，不生成色块。

在“偏好设置 → 颜色别名”每行输入“颜色 = 别名”，点击“保存颜色别名”立即生效并保存在本机，例如：

```text
#0066FF = 品牌主色
rgba(0, 102, 255, 0.5) = 半透明主色
```

最多 32 项，别名最多 64 字；支持 CSS 六/八位 Hex 或数值 RGBA，精确匹配颜色和透明度，同色重复项会提示。属性搜索能找到别名、Hex 和 RGBA，清除后恢复原折叠状态。“清空别名”只清除输入，保存后移除。别名不写入快照，原始颜色始终保留；本机保存失败会明确提示。

### 可选：减少树中的内部层级（新源码）

在“偏好设置 → 默认折叠”，或左树底部设置图标的“默认折叠设置…”进入。新配置默认按组件展开：列表显示到每张卡片，卡片、导航栏和标准控件内部先收起，双击某张卡片只展开它，并跳过已确认没有自身画面的容器。组件按标准 Android 类型或可靠的 SDK 继承信息识别，不猜测自定义类名。已有配置保留原来的选择；当前页面可点树上方“按组件”切换。

超过 300 个节点的复杂页面，开启组件规则且未指定层级时，默认展示到第三层有画面的容器，空容器不占这个层数。收起的分支以整张合成图显示，双击再展开内部；“全部”仍可展开完整结构。渐进采集会在图片补齐时完善这个概览，一旦开始选中或展开控件，就保留你的操作。

“初始显示层级”留空为不限，填5表示显示到第5层，根节点为第1层。“默认收起的类型”每行填写一个具体类名，例如`SvgView`或自有App的`com.example.LoadingView`。这些自定义规则按完整名精确匹配该类，短名匹配各包同名类；区分大小写，不匹配继承或通配符。最多32项，每项200字，层级1–200。

“保存设置”作用于下次采集或打开文件/历史，不改变当前树；“应用到当前树”立即重设展开状态，保留选中节点的路径。采集、刷新、筛选和聚焦时暂不能应用，结束后可用。要默认全部展开，可关闭标准组件规则并清空层级和类型限制，再保存；只临时查看完整树可点“全部”。

收起后仍保留完整节点、属性和图片。可手动展开、搜索或点击“定位”；搜索临时显示路径，清除后恢复，定位会展开选中路径。渐进采集/局部刷新保留已有分支的手动状态；新分支使用该轮规则。2D/3D仍为展开看自身、折叠看分支，离线缺图按原提示展示。

3D 按原始绘制顺序和矩形遮挡关系安排整数层号，所有真实图层使用同一个层距。互不重叠的内容可共用一层；重叠内容至少相隔一层，不再按组件强行对齐。空容器默认隐藏，图片缺失或采集异常的图层保留定位边界。“完整结构”临时显示透明容器的真实边框与完整层距，保留手动隐藏和树的展开状态。

侧视时普通边框保持细线和稳定强度，不再随深度或角度逐渐消失。完整结构中的透明容器也使用清晰边框，原始图片透明度保持不变；选中和悬停仍使用高亮定位。

默认“层叠”视角为水平32°、俯仰0°、层间距128，透视距离1520。页面保持较大的正面面积，图层之间留出清楚的间隔。“展开”使用水平48°、俯仰0°和层间距208，避免预设过于侧向。缩放只改变画面大小，不改变近大远小的比例；旋转、适应画布和测距使用同一套投影，手动旋转仍可观察任意水平角度。

## 5. 只读共享这一份快照

保留刚打开的历史快照，选择 **文件 → MCP → 共享当前快照（只读）**。确认这是要共享的页面，在弹窗点 **共享这一份**。共享内容包括控件文本、属性和已采集图片；本机查看可直接使用 CLI。

CLI/MCP 需要 Node.js 22+。App 内置 CLI；将下例路径替换为实际 App 路径。源码运行时，`inspector_cli` 改为 `dist-electron/cli.cjs`。

```sh
inspector_cli='<实际 App 路径>/Contents/Resources/cli/android-ui.cjs'
node "$inspector_cli" snapshot --pretty
node "$inspector_cli" tree --snapshot '<返回的 snapshotId>' --depth 20 --pretty
node "$inspector_cli" attributes --snapshot '<同一 snapshotId>' --node '<tree 返回的节点 id>' --pretty
```

这些命令读取已共享数据，不重新采手机。桌面须保持运行，查询使用同一 `snapshotId`；静态只读共享直接查询即可。更多查询见[CLI说明](CLI.md#查看页面)。

上例使用普通配置。指定独立配置目录时，CLI 追加 `--snapshot-file '<配置目录绝对路径>/mcp/current.json'`；MCP 使用该窗口复制的配置，其中的共享文件路径应指向同一目录。

已有本地 MCP 客户端时，选择 **文件 → MCP → 复制 MCP 配置**，添加复制的配置并重连；依次调用 `get_snapshot`、`get_tree(snapshotId, depth=20)`、`get_node(snapshotId, nodeId)`，使用前一步返回的实际 ID。配置指向当前 App 自带的服务，读取同一份共享快照，接入方式见[MCP说明](MCP.md)。

## 桌面任务模板、步骤差异与证据导出（新源码）

在首页或工作台“更多工具”打开“任务模板”。填写目标，选中控件后点击“使用选中控件”，再选择出现、消失、启用或禁用条件；也可手动填写精确属性。支持按序阶段和最终条件。填写模板名称后保存，读取模板会替换草稿；更新、另存、删除均只影响本机模板，离线也可编辑。最多30份模板，任务沿用5阶段、20条件和12KB上限。

要执行验收，先按原流程开启自动调试，再在第一次手机输入前点击“固定草稿到当前会话”。固定后条件不能修改；选择阶段或最终条件，再点击“只读验收”。这会按已有 Checker 采集两次新观察，不点击手机。当前快照的匹配数量只是编辑参考。

“查看调试记录”或导入本地 `report.json` 后，步骤详情显示前后差异，验收步骤显示两次观察的差异。只有同一页面实例和窗口中的唯一资源 ID 可确认匹配；重复、无稳定标识、旧观察或缺少身份时显示未知。差异不会改写验收结论。

在报告中展开“导出调试证据”，选择当前步骤或全部步骤，并勾选要包含的树、截图和日志。点击导出后选择保存位置，生成含 `report.json`、附件和设备/App/桌面版本说明的独立文件夹；把整个文件夹交给别人即可重新导入。排除树或前置验收证据时，导出副本不能继承通过结论。画面和控件文字可能包含个人信息，导出前请按需要选择内容。

导出不会采集手机或改写原报告；取消、源文件改变或证据校验失败会停止并说明。当前仅新源码可用，本轮没有更新安装版。

## 模板共享、复用片段、匹配诊断与运行对比（新源码）

模板窗口可导入或导出JSON，分享已保存的模板和复用片段。导入同名项会跳过并列出名称；现有模板及编辑中的草稿保留。无效文件或超过容量时整批不写入。模板与片段共同受512KB限制，最多30份模板、60份片段。

填写片段名称，把单个条件或完整阶段存为片段，再选择插入最终条件或已有阶段；阶段片段会作为新阶段加入。插入保留精确属性和条件顺序，生成新的唯一编号，超过阶段或条件上限时保留原草稿。

每个条件下展开匹配诊断，可查看当前快照里的精确候选、重复原因和逐字段差异。参考候选不能作为精确命中。“查看控件”会关闭编辑器，选中当前树里的对应控件并显示画布高亮；未保存草稿会保留，重新打开可继续编辑；快照变更后须重新查看。

在测试报告中载入另一份调试报告进行运行对比。两份记录必须属于同一App，并声明相同的完整目标、阶段、条件和顺序；每次生成的任务编号可以不同。对比显示两侧验收结论、失败条件和有明确记录的耗时；未验阶段、缺少树或前置证明显示未验收或证据不足。取消或载入失败保留原对比，换主报告会清除对比，主报告的证据导出继续可用。

当前仅新源码可用，安装版尚未更新。
