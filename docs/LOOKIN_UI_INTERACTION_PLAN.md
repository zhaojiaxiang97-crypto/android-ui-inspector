# Lookin UI 与交互细节优化计划

日期：2026-10-13。状态：待实施。本次交付为计划文档。

建议先做 **属性栏紧凑化、常用工具与状态整理**，再补 **2D 测距、候选选择和搜索建议**。目标是让“找到控件 → 看懂属性 → 比较尺寸 → 回到原位置”更顺手。

## 1. 评估依据与现状

本轮查看了当前源码预览、Lookin 本机偏好界面和双方源码。2026-10-13 核对 Lookin Develop，仍为 [`95e30fd`](https://github.com/hughkli/Lookin/tree/95e30fdcc8151092678387c5262bce790a0d9530)。Lookin 当前未连接 iOS App，运行中的 App 交互未实测，相关结论来自固定源码。

以当前源码能力为基线，安装版范围另见[交付说明](DELIVERY.md)。已有能力详见[迁移计划](LOOKIN_MIGRATION_PLAN.md)，不重复列为新功能：

| 已有能力 | 本轮看到的改进空间 |
| --- | --- |
| 三栏工作台、属性分组显隐、长文本阅读 | 身份和关系卡片占用较多高度，尺寸信息靠后；分组折叠还没有独立的持久化偏好 |
| 测距、A/B 重选、固定结果、临时快捷键 | 入口和操作逻辑绑定 3D；普通 2D 截图无法使用，也没有专门的结果复制入口 |
| 快捷选择折叠内部、候选悬停、键盘选择 | “选择内部控件”的用途不够直观；大量同名容器需要反复辨认 |
| 树搜索、属性搜索、路径导航、聚焦恢复 | 树搜索没有输入候选；关联跳转后没有统一的查看前进/后退 |
| 场景提示、状态说明、显示强度设置 | 底部常驻说明较长；整体外观固定为深色 |

## 2. 具体计划

### P0-1：属性栏先展示最常看的信息

**借鉴：** Lookin 按属性类型组织紧凑字段，记住分组折叠；其默认折叠项包含 Class。[属性分组与折叠](https://github.com/hughkli/Lookin/blob/95e30fdcc8151092678387c5262bce790a0d9530/LookinClient/Dashboard/LKDashboardViewController.m#L185-L216)、[默认偏好](https://github.com/hughkli/Lookin/blob/95e30fdcc8151092678387c5262bce790a0d9530/LookinClient/Manager/LKPreferenceManager.m#L188-L190)。

- 顶部保留一份控件身份摘要，随后展示 X / Y / W / H 和实际存在的文本、颜色；完整继承链、原始属性和详细关系放在可展开区域。
- 合并重复的名称与类名展示，缩小卡片内边距；只读数值采用可复制的值样式，避免看起来可以直接修改手机属性。
- 记住各分组的手动展开状态。搜索临时展开后恢复，不能把搜索状态写成用户偏好；提供“恢复默认”。
- **验收：** 1280 × 800 窗口中，选中普通文字/图片控件后，无需滚动即可看到身份、尺寸和已有的关键内容；长名称、缺失属性及搜索定位仍正常。

入口：[属性栏](../src/components/NodePropertiesPanel.tsx)、[分组偏好](../shared/inspector-groups.ts)、[工作台样式](../src/styles/workbench.css)。

### P0-2：工具入口和当前操作更清楚

**借鉴：** Lookin 将视图、缩放、测距和旋转作为工具栏操作，并让测距按钮反映启用状态。[工具栏](https://github.com/hughkli/Lookin/blob/95e30fdcc8151092678387c5262bce790a0d9530/LookinClient/Toolbar/LKWindowToolbarHelper.m#L55-L122)。

- 工具栏固定分为“设备与采集 / 视图与缩放 / 检查工具”。测距和内部选择保留直接入口，次要设置收进原有菜单。
- 工具按钮显示选中态；状态栏只显示当前操作和相关退出方式，例如“测距 · 选择 B · Esc 结束”。完整快捷键说明从帮助入口查看。
- 3D 不可用、当前节点不能内部选择等情况，提供可用键盘访问的简短原因。设备连接状态与当前画面的采集时间分开表达。
- **验收：** 不查文档可找到测距和退出方式；缩窄窗口后操作不重叠；弹窗、候选、测距的 Esc 按层级处理，一次只退出当前操作。

入口：[工作台头部](../src/components/AppHeader.tsx)、[画布与工具栏](../src/components/ScreenshotPreview.tsx)、[场景提示](../src/components/ContextHint.tsx)。

### P1-1：普通 2D 截图也能测距，并能复制结果

**借鉴：** 沿用 Lookin 的双控件结果区。[测距结果展示](https://github.com/hughkli/Lookin/blob/95e30fdcc8151092678387c5262bce790a0d9530/LookinClient/Measure/LKMeasureResultView.m)。**2D 接入和复制结果是本项目扩展**，不声称是原版完全相同的功能。

- 将已有 A/B 选择、固定和结果卡接到 2D；从树或截图选控件，保留现有 3D 用法。只有边界、没有独立图时仍可测距，并说明图片缺失。
- 增加“复制结果”：包含 A/B 名称、比较的边缘、数值、单位和当前快照标识，方便贴到问题描述中。
- 首版继续使用屏幕 px；dp 换算待确认存在可靠的 Android 密度数据后单独安排。截图裁剪图不能标成独立图，画布缩放不能改变测量值。
- **验收：** 同一快照的相同 A/B 在 2D、3D 和不同缩放下结果一致；包含、重叠、四边对齐和缺图均有清楚结果；换快照清除旧配对。

入口：[测距逻辑](../src/features/layers/useLayerMeasurement.ts)、[结果卡](../src/features/layers/MeasurementCard.tsx)、[测量数据](../shared/measurement-card.ts)。先整理视图无关的测量状态，再接 2D 命中。

### P1-2：内部控件选择更容易理解

**借鉴：** Lookin 的 Command 临时选择折叠内部；本项目已有对应快捷键和候选列表。[选择处理](https://github.com/hughkli/Lookin/blob/95e30fdcc8151092678387c5262bce790a0d9530/LookinClient/Static/Preview/LKPreviewController.m#L396-L422)。

- 入口提示改为“选择折叠内部的控件”，面板明确显示当前分支和“按布局边界匹配”。
- 候选优先展示可辨认的文本或资源 ID，再展示类型和相对路径；增加当前候选范围内的过滤，数量明确区分总匹配和当前页。
- 沿用悬停预览、上下键、Enter 确认、Esc 取消；打开位置避开点击目标，空间不足时停靠画布侧边。
- **验收：** 同名、重叠和深层节点可辨认；过滤不改变原树；悬停不改选中，取消恢复原操作，确认才展开并定位目标。

入口：[候选面板](../src/features/layers/QuickSelectPanel.tsx)、[候选计算](../src/features/layers/quick-select.ts)。

### P1-3：搜索时给出已有数据里的候选

**借鉴：** Lookin 输入组件支持建议列表及上下键、Enter。本项目把这种交互用于树搜索，属于改编。[输入候选组件](https://github.com/hughkli/Lookin/blob/95e30fdcc8151092678387c5262bce790a0d9530/LookinClient/Base/InputSearch/LKInputSearchView.m#L107-L145)。

- 基于当前快照提供文本、资源 ID、类型候选，精确匹配优先；明确显示候选类别，避免相似名称混淆。
- 输入与确认分开：上下键预选，Enter 采用候选，Esc 先关闭建议；继续复用原树筛选和结果定位。
- **验收：** 中文输入法组合输入期间不误确认；大树候选有数量上限；换快照清旧；清空筛选恢复原展开和滚动状态。

入口：[控件树](../src/components/UiTree.tsx)、[筛选与导航状态](../src/features/inspection/useInspectionWorkspace.ts)。不新增第二套搜索页面。

### P2-1：查看过的控件可以前进、后退

这是本项目对连续检查流程的扩展，不归为 Lookin 已核实功能。

- 在当前快照内记录显式选择和关联跳转；提供“上一个查看控件 / 下一个查看控件”，同时恢复必要的树位置和属性阅读位置。
- 悬停、搜索预览不进入记录。记录有上限；换快照清空，局部刷新后仅保留能够确认身份的目标。
- **验收：** 从控件跳到父级或约束目标后，可返回原控件；返回不会恢复失效节点，也不会向手机发送返回键。

入口：[现有导航](../src/features/inspection/useInspectionWorkspace.ts)、[父级路径](../src/components/NodePathNavigator.tsx)。

### P2-2：浅色、深色和跟随系统

**借鉴：** Lookin 本机偏好已提供“外观：跟随系统”，源码保存外观选择。[外观偏好](https://github.com/hughkli/Lookin/blob/95e30fdcc8151092678387c5262bce790a0d9530/LookinClient/Manager/LKPreferenceManager.m#L249-L255)。

- 通过现有颜色变量增加三种外观选择；保持工具位置、字段密度和颜色含义一致。
- 检查树选中、悬停、虚线边界、测距蓝/橙和透明棋盘在两种外观下的可辨认程度。
- **验收：** 切换主题不改变快照、选中和测距状态；重启保留偏好；系统模式能响应系统变化，截图原始像素保持原样。

入口：[颜色变量](../src/styles/tokens.css)、[偏好设置](../src/components/PreferencesPanel.tsx)。

## 3. 实施顺序

| 批次 | 内容 | 交付判断 |
| --- | --- | --- |
| 第一批 | P0-1 属性栏 + P0-2 工具与状态 | 先让同一份离线样例的主要信息和操作更容易找到；用改动前后界面确认 |
| 第二批 | P1-1 测距 → P1-2 内部选择 → P1-3 搜索建议 | 每项独立验收，保留现有快捷键、测量语义和导航恢复 |
| 第三批 | P2-1 查看历史、P2-2 外观 | 前两批通过后再安排；主题覆盖面较大，单独收口 |

首批保持当前深色工作台、三栏布局和蓝色选中主色。通过减少重复内容、收紧留白和清楚表达状态改善体验；不增加装饰动画。2D 测距、搜索改编和查看历史分别标注为本项目方案。

## 4. 验证与范围

- 使用项目自有离线样例，覆盖长文本、深层树、重复 ID、缺图和部分采集；不把业务页面截图写入公开文档。
- 以 1280 × 800、1440 × 900 和当前最小窗口 960 × 700 检查布局；覆盖键盘操作、中文输入法、100% / 125% / 150% 页面缩放及减少动态效果。页面缩放与物理显示 DPI 分开记录。
- 扩展现有树 UI、属性搜索、画布坐标和测距检查；每批运行相关测试、类型检查及构建，并实际操作一次“找控件 → 看属性 → 测距 → 返回”。
- 交付分别记录源码、预览和安装包状态。文档完成不代表产品功能已经实施。
- 本计划沿用已有采集、快照和授权链路。Figma 对比、实时修改 App 属性、事件信息采集和自动化执行扩展另行规划。
