## 技术方向判断

**保留 Debug App + 进程内 SDK + WebGL，不推倒重写；优先解决数据一致性，再收敛采集通道。**

- SDK 适合读取真实 View 树、属性和各层自身画面；WebGL 适合层级展开及交互。
- 当前主要风险是先读树、再逐层绘制，以及 SDK/DDMS/JDWP 多通道跨时刻拼接。单控件同任务绘制不等于整页同帧；局部重试只能缓解动态失配。
- 新版 SDK 应成为接入 App 的主通道；旧通道保留为明确的兼容选项，不把普通层失败升级为长时间整页回退。这是待实施方向，不是当前已完全实现的行为。
- 隐藏接口继续用于 Debug，但要按系统版本检测能力，失败明确标注；先稳定原生 View，不并行扩展所有 UI 框架。
