分支折叠检查必须先确认该父层有实际展示的子层；按子层ID消失判断，不能只比较总层数。业务合成检查还需独立图证据，无独立图的fixture只验折叠/恢复结构。完整采集应在交互前保存快照；失败报告保留折叠前的层ID。点击测试要求坐标当前落在canvas上，选择后的悬停不能沿用旧位置，因为旋转中心可能变化。

手机整组图入口：`bun scripts/live-group-probe.ts <snapshots.json> <branch ID>`，单次调用正式取图，25秒取消预算、失败保留、结束释放自身连接。离线对照追加第三个参数`<live-group/group.png>`；先校验报告成功、来源路径、分支ID和PNG SHA，再检查原始尺寸及100k输出，两者RGBA均完全一致才通过。来源路径不等于快照内容摘要；不同时间采集不证明同帧一致。固定内容对照需排除页面变化，再判断软件/硬件绘制取整差异。不绕过Surface/Texture或复杂outline拒绝规则，不替换生产SDK来掩盖未定位色差。

来源门禁：composite/native仅表示渲染角色，不表示SDK来源。工作台报告须保存data-layer-image-source和data-layer-group-state；live-group必须ready，本地合成可为pending/unavailable/not-live/hidden-descendants。旧快照unknown不从tree-source反推；渐进更新必须携带来源字段。隔离组件模拟pending→成功或null、单次请求、展开恢复own通道；真实设备需等请求结算或明确有界超时，不能固定600ms后将composite当原生成功。null原因未返回时照实保留，不伪造几何/权限/系统失败原因。

## 功能通过标准

- 树选择/折叠/筛选/键盘/定位稳定；大树挂载行数有界，旧快照状态不泄漏。
- 首次展开可见后代，选择不重排 Z；own/group、透明度和已知裁剪不串层，隐藏仅影响查看。
- 图片、边框、高光和命中使用同一可信几何；未知父链/轮廓明确回退，不伪造位置。
- 旋转/平移/缩放和窗口外释放正确；reduced-motion 关闭动画但不影响功能，渲染错误为 0。
- 缺属性显示未知，不把 Android bounds 伪装成完整 CSS 盒模型；长文本不撑破面板。
- 请求取消或替换后，旧成功/错误/finally 不改新树、选中、提示或忙态；历史切换不恢复旧在线快照。
- 首采反馈：`tests/capture-feedback.test.ts`验证窗口/读树/复核/后续失败分类、旧快照兼容、取消不复用旧时间、成功保留失败和8条上限；`bun run test:tree-ui`验证手动重采仅发一次请求、恢复、历史切换、取消后迟到结果，以及1280/960宽度布局。截图留本机`.benchmarks/capture-feedback-*.png`；不是手机启动或性能验收。

- JDWP字段合并：`tests/view-debug.test.ts`的fallback协议fixture确认mPrivateFlags/mOverlay同对象一次读取、单字段兼容像素一致、数量/标签/截断/尾部错误失败且不重试；SKIP_DRAW不能吞掉继承dispatchDraw或overlay，缺overlay字段不影响非SKIP_DRAW绘制，错误/取消后释放对象和调试挂起。不是业务性能或跨Android版本验收。

## 失败与发布规则

P0（无法启动、数据损坏、未授权写入、错误命中、安全失效）和 P1 主路径回归阻断发布；环境缺证据明确写“未验证”。非主路径 P2/P3 进入排队，不扩大当前任务。

普通自动化间歇失败可同条件人工复测一次，但首轮不能删除。严格性能对照不筛选成功轮，设备失败先分析；不增大产品 timeout、跳断言或关闭安全项。

报告至少包含日期、源码状态/摘要、命令、环境/权限、数据覆盖、全部尝试与错误、实际路由、耗时口径、检查项、产物路径和限制。业务 XML/PNG/APK/日志只在被忽略的 .benchmarks/，fixture 必须合成脱敏；公开摘要不带账户/序列号/私人内容。

阶段交付必须满足：相关 T0–T5 通过、失败/未测项明示、文档同步、无真实数据或构建产物混入 diff。通过旧版本记录不自动继承新版本；最新全量通过数字由 [状态文档](../PROJECT_STATUS.md) 统一维护。
