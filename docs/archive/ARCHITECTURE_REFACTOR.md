# 结构重构

更新：2026-10-08。结构重构及统一本地验收已完成，不继续为缩行拆模块。下一步冻结重构候选、准备交付；安装与重启另确认。导航和真实桌面同步缺口保留，暂不操作手机。原输入留证及撤销结果见[核心验收](../CORE_ACCEPTANCE.md)。

## 目标

按职责找代码，入口只编排流程，协议解析和纯算法可独立测试。保持现有功能、超时、取消、授权及采集语义；不新增框架、依赖、兼容转发层或全局服务容器。

## 重构前的问题

- `electron/adb.ts`约3800行，混合设备、命令、SDK会话、树解析、图层匹配、Qt和采集。
- `src/App.tsx`约1240行，混合页面编排、定位器、快照比较和历史界面。
- `Layer3DPreview.tsx`约1250行，混合GPU资源、着色器、投影、纹理和React生命周期。
- 产品输入模块反向依赖`scripts/`的执行器；诊断工具与产品模块边界不清。
- 目录文档已落后于真实代码，不能当导航使用。

## 实施顺序

1. 保存重构前源码及测试基线，记录原运行版本；不覆盖当前桌面安装包或手机SDK。
2. 拆分设备运行、SDK通信/协议、树与图层解析；按设备、采集、SDK、自动化、桌面、平台分目录。调用方直接引用所属模块，不保留旧路径转发文件。
3. 抽出界面的纯定位器/快照模型、历史展示和WebGL渲染职责；页面保留跨组件编排，不逐个状态制造抽象。
4. 整理诊断目录、更新实际导入和构建入口；增加可运行的结构边界检查，防止产品重新依赖诊断脚本。
5. 全量测试、构建、树/坐标/WebGL/桌面合成回归；更新目录说明及当前状态。新源码构建通过不等于桌面/手机已更新或真机问题已修复。
