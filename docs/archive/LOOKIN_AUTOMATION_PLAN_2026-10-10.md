# Lookin 对齐计划

更新：2026-10-10。本页只维护下一步的顺序、交付物和完成条件。能力看[状态](../PROJECT_STATUS.md)，实际版本/结果看[验收](../CORE_ACCEPTANCE.md)，通用标准看[测试计划](../TEST_PLAN.md)。

A已收口：同一安装候选在业务设置页只读采集一次，实际属性栏、2D/3D联动及小窗口滚动通过；历史与报告未变。下一项只做B1离线取消/迟到/恢复组合验收，不追加手机采集。旧工具截图差异仍保留，单页通过不代表全部兼容或性能完成。

## 方向与取舍

目标仍是安卓 Debug UI 检查工具，并在此基础上实现受控自动化：真实控件树、WebGL分层、点击查属性；展开看自身，折叠看分支。

当前已有检查工作台、确定性e2e单轮、报告和只读诊断。属性联动已交付并完成真机单页复核；取消后恢复与取图阶段取消仍缺当前入口的组合验收。先完成最小可靠性闭环，再增加自动化入口，不继续无限扩展SDK探针。

保留SDK + Electron/React/WebGL、DDMS/JDWP兼容补采与Qt/QML专项路径。结构重构已收口；不重写采集体系、不另建通用适配层、不把全部机型/框架兼容当下一功能的前置条件。已知限制仍明确保留，不冒充通过。

只完成这一候选/机型/页面的属性复核，不是严格像素、取消恢复、跨机型或长期性能验收；详见[本轮记录](CORE_ACCEPTANCE_2026-10-09.md#A3属性复核)。

## B. 补当前诊断的取消与恢复缺口

不是重新实现已存在的取消机制。已有单元、真实socket替身和交接测试；缺口在实际组件、包内代码及当前安装入口的组合验收。

### B1. 离线可控时序——实际下一项

复用现有交接/传输测试与隔离窗口，延迟只加在测试桥接/替身中，不阻塞手机UI、不修改产品期限，也不随包开启。

| 场景 | 必须看见 |
| --- | --- |
| 树阶段取消 | 原请求被取消；迟到树/成功/错误不回填；按钮和忙态正确 |
| 取图/图片度量阶段取消 | 已到首图后取消；迟到分片/worker结果不更新树、属性或提示 |
| 关闭报告或切换设备/快照 | 原请求停止；重开或新页面不接旧回复 |
| 原请求未收尾时再发起 | 不并行污染；旧取消不终止新请求，旧finally不清新忙态 |
| 30秒超时/传输失败后恢复 | 原因只记一次；一次新请求成功，身份和图像分类重新核对 |

覆盖取消前后事件、成功/失败回复与清理时序；同时看实际DOM/画面、调用次数和请求ID，不能只检查setter。沿用`tests/desktop-capture-handoff.test.ts`、`tests/live-diagnosis.test.ts`、`tests/provider-session-request.test.ts`和`tests/provider-session-transport.test.ts`，缺什么补什么，不复制第二套采集状态机。

### B2. 再限定真实验证，不连续采集等时机

- B1与候选包内复验通过后，分别确认“取图阶段取消一轮”和“取消后恢复一轮”的范围；不能沿用旧许可，也不把两者偷偷并入普通只读复核。
- 本轮计划不把物理拔线放在第一批；先做软件取消/关闭/恢复，手动断线作为另约专项。已有树阶段取消证据保留，不重复验证来增加数量。
- 如果采集先完成、取消未送达，记“未覆盖”，不记通过也不自动重测。手机无响应、身份变化或资源状态未知，保存记录后停。
- 核本次socket、转发、等待项与监听器；正常成功SDK连接可复用，按默认空闲5分钟回收规则检查。不强制清其他会话，也不从“转发为空”推断全部远端任务/内存结束。

完成：固定候选下，取消不污染新结果、原期限外无回填，受控恢复有新请求证据；真实/本地及未覆盖项分别记入验收。发现失败只修最小原因，优先离线复验，再明确是否需要新真机轮。

## C. 做一个用户能使用的确定性自动调试入口

当前e2e仍是独立实验，报告按钮只负责导入/查看；桌面尚没有运行e2e用例的产品入口。这一阶段是新增功能，不把一次外部成功当产品已完成。

### C1. 先明确执行器边界

- 以已验证的e2e确定性路径做首个受控执行实验。Inspector负责真实图层、属性和诊断；CLI/MCP保留既有能力，原导航问题不被e2e通过覆盖，不建设第三套执行引擎。
- 接入前核依赖/许可、Node运行时、助手来源、唯一设备、固定App、操作许可、退出与资源归属。外部实验目前不复用桌面授权，不能把环境变量当安全边界；未解决就维持独立，不先做“一键执行”。
- 若接入桌面，外部runner由主进程有界管理，UI仅调用声明的接口；不能从产品导入`scripts/experiments/`，也不开放任意命令、脚本路径或原始shell。
- 操作使用语义定位/唯一目标及断言，逐步留截图；不为每次点击都采完整Debug图层，避免深度取图拖慢测试。Inspector深入采集仍显式触发，是新现场，不冒充失败当时的树。

### C2. 首版只支持两个固定用例

1. 自有样例：确认初始文字→点击一次→确认文字变化与新增控件。
2. 业务稳定页：确认“设置”和唯一“播放设置”入口→进入一次→确认目标标题→按原确认范围返回一次→确认原页。

先本地/自有样例，再另确认业务轮；单设备、单worker、零重试、固定时限。目标不唯一、页面不符、输入结果未知就停，不扩大导航范围、不改任何业务设置。

桌面最小交付：用例/目标/操作预览、开始确认、运行阶段、停止、结果和报告入口。沿用现有报告索引/诊断组件；停止需区分“已请求”“主机已退出”“远端收尾已确认/未知”，杀runner不等于已撤销手机输入。

完成：用户不需手动拼终端命令即可运行已确认用例，成功/失败/停止均有独立报告；查看失败证据、再显式采当前页、定位属性形成闭环。坏报告/缺图/拒绝/未知收尾不伪装成功，旧报告与历史不覆盖。真实输入次数与步骤记录次数分开。

## D. 再接自然语言，先做受限版本

先解决“用户说一句话，系统生成可检查的步骤”，不直接让模型自由操作手机。

- 用户先选择模型、数据发送范围和费用上限；不借用登录/API Key。默认只发送最小必要文本，截图/控件数据上传单独确认。
- 模型只生成白名单动作与断言的结构化计划，首版最多5个动作；用户预览修改并确认后，才交给C的受控执行器。执行总时限沿用受控用例预算，模型等待/调用次数另设上限并全部计费留证。
- 缺目标、同名歧义、非法动作、未知页面和超预算在执行前拒绝。模型不能改包名、扩大授权、生成shell、延长期限或重试未知输入。
- 首先用本地假模型测试正常、坏格式、危险动作、歧义与超预算；通过后另确认一次真实模型/自有样例实验。遇动态变化先停并提示，不自动重规划继续点击。
- 报告分别标模型计划、用户确认、实际步骤、断言、用量与收尾；用量未返回就记未知，不填0。模型判断不等于设备实际成功，不把只读诊断的全部背景状态当严格像素结果。

完成：一条限定自然语言需求可生成计划，经确认执行并回看证据；拒绝与失败路径同样可用。未选模型/未确认数据之前，D不启动。

## E. 暂不抢占主线的专项

- 冷启动：先限定App就绪、SDK排队或传输中的一个问题及一次观察；根因未证，不增加超时、重复启动或恢复采集假装修复。
- 复杂半透明/裁剪：用最小样例和同候选严格RGBA对照处理已知差异；保持零差异标准，不用容差盖掉旧失败。
- 兼容/资源：更多Android/OEM、框架、多窗口、物理DPI/显示器与长期资源按风险分批验证，不承诺任意绘制节点可读。
- 发布：固定目标平台包、干净系统安装/升级/回退、正式签名/公证与完整入口回归。P0/P1主路径或安全失败阻断发布；公开代码推送与正式发布分开，均需明确范围。

## 完成后怎样收口

每批只交一个可验收结果：候选/源码差异、具体检查与全部尝试、耗时口径、截图/布局、身份与资源、失败和限制。文件放每轮新的本机忽略目录，不发布业务数据。

通过后更新[验收清单](../CORE_ACCEPTANCE.md)和必要的[状态](../PROJECT_STATUS.md)，从队列移除完成项；逐轮细节只进归档，不再反复膨胀本页。完成A+B后开始C，不因全部P2未完成而长期停在探针测试；安全或核心数据风险仍先解决。

## 执行边界

- 仅支持Debug App；不裁整屏冒充独立图，不把缺图/skip-draw猜透明，父背景与子自身画面分开。
- 身份、窗口、几何、裁剪、DRM、期限、取消和迟到保护不放宽；未知输入不盲重试。
- 稳定页3次≤15秒、首图送达→GPU完成≤500ms仍是验收目标，不是当前稳定承诺或物理上屏；不为本次写计划追加性能采集。
- 本地准备可以先做；桌面/手机更新、重启、手机采集/输入/恢复、故障注入、模型上传及发布必须明确本轮范围。过去许可不自动延用；不擅自卸载/清数据或修改安全设置。
- 正常SDK连接可复用，默认空闲5分钟回收；自有资源与远端状态分开，不清理其他会话。App无响应、身份/收尾未知立即停止。
- 本轮依据当前代码、本地准备和既有记录推进，没有重新研究Lookin/e2e上游或检查GitHub同步；历史依据看[归档](README.md)。
