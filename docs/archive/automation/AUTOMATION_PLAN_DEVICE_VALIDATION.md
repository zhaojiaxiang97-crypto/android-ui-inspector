# 操作计划真机回测

更新：2026-10-17。新版已连续完成两轮真机“首页→我→首页”，修复并复测了容量误停，也完成逐步CLI基线。设备为一台 Android 手机，目标为快手 Debug 版，两次授权会话均固定 UIAutomator，未安装或修改 Helper。

## 已确认的结果

| 项目 | 结果 | 耗时 |
| --- | --- | --- |
| 首次只读采集 | 119节点，成功 | 7.331秒，其中树读取6.854秒 |
| 只读计划 | 起点、等待、终点均通过，0输入 | 产品23.707秒；提交回执132.7毫秒；查询见终态墙钟25.826秒 |
| 同编号重复提交 | `replayed=true`，返回相同结果，没有新增计划产品步骤 | 不计为新一轮 |
| 单独准备个人页、首页 | 各1次输入，分别验证成功 | 产品15.228秒、12.509秒；不计为计划闭环 |
| 首次两步动作计划 | 第一条点击及个人页验证成功，因容量记录错误停止；第二条未执行 | 产品20.802秒；首步13.215秒；提交回执137.2毫秒 |

首次会话共3次输入，没有重发或独立恢复，最终停在个人页；旧授权已停止。这份修复前动作计划整体为失败，不能用首步验证成功替代整段通过。

只读计划6次观察合计22.333秒，占该计划94.2%；保存合计96.5毫秒。控件树与截图阶段有重叠，不能把分段简单相加。当前样本说明设备观察仍是主要耗时，没有证明正常流程已提速。

## 真机发现并修复的问题

报告接近32MiB上限时，按既有优先级裁掉了一张最早的预备截图。当前动作的前后两份树、两张PNG均完整，长度和SHA256匹配，但历史裁剪被加入当前步骤的`recordingErrors`，计划因此返回`evidence_recording_failed`。

修复位于[证据写入器](../../../electron/automation/debug-evidence.ts)：历史附件正常淘汰保留快照警告；当前步骤必需的前后帧、视觉确认、滚动输入与确认、任务验收双帧被裁剪时仍返回错误。容量上限、淘汰优先级、真实写盘和请求台账失败处理没有放宽。

相关210项/14文件通过，工作树与原目录类型检查和完整构建通过。新增9项包括完整会话的“旧截图淘汰后继续执行”和“当前证据存不下则停止后续输入”；独立审查及这9项复跑也通过。离线测试与下面的真机结果分别解释。

每份自动计划只提交一次，起点、两条动作与最终条件均通过。两轮分别完成10次观察，耗时39.482秒和38.233秒，占整段92.05%和91.41%；输入阶段2.185秒和2.340秒，保存0.171秒和0.183秒。步骤阶段存在嵌套，分段不继续相加。

第二轮同编号重提返回原结果，产品步骤保持14→14，已发送输入保持5→5；没有重新执行。该新会话最终共7次输入：准备首页1次、两轮计划4次、基线2次；全部完成验证，无未知输入、重试或独立恢复。手机最终为首页，会话已停止。

停止授权后报告为32,505,322字节，低于32MiB上限；6份历史快照保留容量警告。第二轮及基线动作的当前前后证据完整，计划没有被正常历史裁剪误停。报告现存40个附件的长度及SHA256全部通过核对；后续写入已裁掉第二轮起点的一张历史截图，不能宣称所有历史图片一直保留。

两轮计划与一次CLI基线是功能和容量冒烟，不是10轮稳定性或多设备验收。基线只含两个动作，计划额外包含起终点双帧检查与管理开销，约15.785–17.644秒；两者总计时范围不同，且CLI基线没有模型思考时间，本次不发布稳定提速比例。

提交回执时间只表示接收；产品总时间来自`run.durationMs`；查询见终态的墙钟含查询间隔。动作步骤的耗时不能当作整段耗时，CLI基线也不包含模型思考时间。

## 下一步优化方向

已确认正常路径可以由执行器连续完成，接下来优先优化占九成时间的观察。第一步是[手机侧有界条件等待](../../HELPER_CONDITION_WAIT.md)：条件尚未就绪时设备内部短时查询，只返回小型调度提示；就绪后仍由桌面获取新的完整树图并做双帧确认。该优化仅作用于显式选择的 Helper 后端，不改变本次 UIAutomator 基线，具体实现与验证状态见该文档。

保留唯一目标、窗口和授权检查，关键边界仍采集证据。此次没有实现手机端解释器，也没有改变默认后端或减少现有验证次数。

后续已完成 Helper 短时等待实现、163 项相关测试及单台设备只读冒烟：持续未就绪的 15 秒用例只做 1 次完整观察，其余使用 10 次手机查询；取消及取消后采集也通过，整轮无手机输入。它尚无同机旧版基线或动态就绪的真机对照，完整计时范围和证据边界见[本轮记录](../../HELPER_CONDITION_WAIT.md#只读真机结果)。
