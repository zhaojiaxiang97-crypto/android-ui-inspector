## 已实现能力

| 范围 | 能力 | 边界 |
| --- | --- | --- |
| 采集 | 默认标准模式：Debug准入、真实View树、DDMS/JDWP取图；SDK增强可选 | 标准模式不探测SDK、不建立SDK会话；Release拒绝；不保证所有框架内部节点可读或图层精确 |
| SDK增强设置 | 偏好设置→采集→启用SDK增强；默认关闭，主进程持久化 | 忙碌中不能切换；保留快照但旧实时会话失效，重新采集后才能继续实时操作 |
| 文字样式 | 标准 Debug 树保留字号、粗斜体、当前文字色、对齐、方向和省略方式；显式“读取字体”补充当前 TextPaint 字体家族、数值字重和样式，无需 SDK | 树内样式不增加请求、可离线保存；字体按钮单独实时读取、不存入快照；API34起家族名仍可能未提供，不推测字体文件、逐字符回退或字距/行距 |
| 工作台 | 紧凑顶部、底部树搜索、贴边属性卡片/浮窗；2D/WebGL 3D、树与场景同步、键盘浏览、双击设置、可配置类型/层级默认折叠 | 最多512层，截断提示；大树虚拟化；搜索路径不展开真实场景；折叠不裁剪原树 |
| 图层与画布 | own/group、选中/视口优先解码及受支持路径的整组取图、同次采集缓存、悬停/选择、折叠分支内部候选定位、隐藏/恢复、分支聚焦/单层查看、测距、旋转/平移/缩放/适应 | 标准按需独立图由选择/展开/按钮触发；展开看自身、折叠看分支；适应避开属性栏；缺图不能猜透明或裁整屏补图 |
| 属性与历史 | 名称/继承/几何/原生布局、原生布局目标定位、SDK显式分组/分层业务值、颜色源值/透明色块/精确本机别名、七组显隐/恢复默认、本机保存、搜索临时展开并恢复、完整值复制、控件自身/分支图片预览/PNG导出/复制、历史/对比/完整文件导出与离线打开 | 隐藏不删采集数据；未暴露或无效值标未知；新采业务信息需App接新版SDK且开启增强；已有快照可离线查看，截图与动态层不保证同帧，分支缺图明确标记 |
| 首页与菜单 | 连接/加载/离线/未授权/错误状态、离线历史、共享偏好、菜单与右键统一动作/快捷键 | 连接失败禁用旧设备；历史下拉可读、AI按钮完整；显式采集与立即停止保留 |
| 更新与恢复 | 渐进预览、单控件/分支/列表刷新、取消、迟到隔离、有界失败记录 | 不等于全部断线、远端任务或内存收尾已验证 |
| 标准采集速度 | 截图与属性准备并行；树、图层、截图分别交付；稳定首轮减少重复窗口查询 | 保留窗口/方向/取消校验；同页树预览明显提前，整页时间仍主要受设备批量取图影响，见[本轮对照](CORE_ACCEPTANCE.md#standard-capture-performance) |
| 标准补图准备 | 仅识别类型或全部为空容器时，跳过 Bitmap、像素数组及位图方法查询；实际取图继续按原路径执行 | 不改变图片数量、编码与补采上限；设备整批图片的等待仍存在，见[补图优化](CORE_ACCEPTANCE.md#standard-bitmap-setup) |
| 标准按需取图 | 桌面默认先读树与截图，选择/展开分支后最多读取32层；实时快速快照点3D自动完整采集，等待保持2D | 待加载不占3D空间；全图失败保留2D，完整结构可显式查看；历史不联网。约2.2秒仅指样例树与截图就绪，不是完整3D耗时，见[验收](CORE_ACCEPTANCE.md#standard-on-demand-layers)和[后续采集方案](CAPTURE_PIPELINE_REDESIGN.md) |

| CLI/MCP | 读树/搜索/图片/测距；授权后复合操作、连续滚动、去重和留证；可选 Helper v1 观察、失败诊断及有界只读恢复 | 默认 standard 与 UIAutomator；deep 沿用桌面模式，单次请求不能开启增强。历史候选单机点击/返回恢复及滚动回测通过，复杂异常仍待验证；当前手机已恢复 A2 实验前原版 Helper，见[规则记录](HELPER_INPUT_TRANSPORT.md#helper-observation-recovery) |
| 连接诊断 | 授权、锁屏、前台窗口、Helper及CLI/MCP状态 | 标准模式跳过SDK声明探测并显示增强未启用；增强模式SDK检查仍为可选，独立CLI/MCP诊断默认标准模式 |

- SDK可选化的新安装版、增强模式真机重采及复杂业务页面验证尚未完成；本轮已完成无SDK文字样例与桌面模式切换验收。
- U6d新版手机单页、诊断取消/迟到/恢复及取图阶段取消：暂停，恢复时重新限定范围。
- 旧工具截图差异、冷启动首采、间歇同步与CLI/MCP导航根因：尚未证实。
- 复杂硬件半透明严格像素、更多机型/框架/多窗口、长期资源及物理DPI：未全面验收。
- 自然语言自动调试、最新跨平台包、干净系统安装、正式签名/公证与发布：未完成。
- A2 已完成扫描阶段计时、同条件计时探针 A/B/A、[Provider 节点 ID 真机审计](OPEN_SOURCE_REFACTOR_EXECUTION.md#a2-provider-identity-audit-20261021)及[完整业务耗时复算](OPEN_SOURCE_REFACTOR_EXECUTION.md#a2-latency-budget-20261021)。发送前扫描未观察到重复虚拟 ID 生成，758 节点仍超时；16 节点框架批次的主要开销是目标端生成节点。D12 距整段 20% 提速仍差 8.534s；D24 已选“我”的 644 节点预检 7/10 超时，正式三轮仍 0/3。尚无可安全合入的扫描提速候选；生产 1 秒门卫、测试 APK、Helper 与自动旋转设置保持原版/已恢复。

源码、隔离工装、安装窗口和手机分别验收；不同版本的单轮结果不拼成稳定性能承诺。历史方案和旧“下一步”不自动恢复执行。
