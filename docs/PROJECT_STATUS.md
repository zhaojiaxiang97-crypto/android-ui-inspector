## 已完成

### 采集与层级

- 只支持可调试的 Android App：通过 `run-as` 校验，不满足条件时直接提示“仅支持 Debug App”。
- 原生 Android 使用 Debug View 层级；Qt/QML 使用 QML Debug 对象树。
- UIAutomator 只用于 fast 观察和自动化操作，不作为深度 3D 层级来源。
- 截图后默认展开全部可见子层；左侧树收起父节点时，右侧同步收起整棵子树。
- 每个层只显示自己的独立画面；没有独立画面时显示边框，不用整屏截图冒充控件背景。
- 3D 展开仍显示每层自己的位图；SDK 提供完整 `clipToOutline` 时，子层纹理会按原始坐标套用自身和祖先圆角遮罩，避免显示现实布局中已被父层裁掉的像素。未知轮廓不猜路径。
- 收起父节点时使用该分支的合成画面，重新展开后恢复子层。
- Qt/QML 在线视图收起父分支时按需抓取真实整组图；展开、隐藏子层或切换快照时不会把整组图误贴到父层自身画面上。抓取时间单独提示，失败仍用原合成画面。
- Android SDK 混合快照也可在在线收起父层时按需抓真实整组图；展开恢复各层自身图并应用已知祖先轮廓遮罩。分支身份、窗口、尺寸或摘要不符，以及含 SurfaceView/TextureView 或圆角轮廓时，仍使用本地合成图。Android 14 样例的嵌套圆角/折叠图逐像素检查及 3D 真机冒烟通过；业务当前页面没有合适的带子项圆角父层，业务像素对照仍待验。无法读取的自定义轮廓不伪造画面。
- 3D 视图支持旋转、平移、滚轮缩放、悬停高亮、选中、隐藏、聚焦、测距和自动取景。
- 属性面板为可拖动悬浮 Tab；树、画布、属性和截图定位保持同步。
- 接入 Debug SDK 的 App 可为控件设置显式调试名称；树与属性栏优先显示它，同时保留真实类名、资源 ID 和名称来源。SDK 返回的 `LayoutParams` 宽高、类型及真实 margin 可查看；未提供时仍显示“—”。
- SDK 混合快照的选中控件可展开查看真实 Java 类继承链；同类控件共用一份继承表，不重复传输。旧快照没有此字段时保持原显示。
- SDK 混合快照新增交互卡：显示可长按、上下文点击、标准点击监听器、按下和激活状态；这些是 Android View 标志，不代表完整的自定义手势能力。未读取到的状态显示“—”。
- SDK 混合快照可查看系统 `FrameLayout` 的真实重力方向，以及 `LinearLayout` 的重力方向和权重；RelativeLayout 常用规则、ConstraintLayout 锚点/偏置/环绕/宽高比已在新 SDK 中实现。2026-09-30 用新 AAR 保留数据覆盖安装业务 Debug App，正式整页采集以真实 DDMS 树匹配 1211 个节点，358 个布局规则节点全量解析通过；新版桌面端在隔离用户配置下完成 1209 节点真机采集，截图确认 RelativeLayout 和 ConstraintLayout 属性规则均正常显示。完整采集约 25 秒，1 个独立图补采失败。旧版桌面窗口和数据保持未动。

### 连续采集稳定性

- 完整属性改用 DDMS `VURT` V2 编码，避开进入调试模式后旧反射导出超时的问题；接入 SDK 且至少 200 节点的页面默认尝试 SDK 可见层图，兼容路径仍使用 DDMS。
- 恢复按对象身份补采父容器自身画面与独立视频缓冲；明确排除子节点，不再使用仅叶子截图的临时方案。
- 纯结构容器、真实透明位图和采集失败分别标记；视频的全透明占位图不再误报为成功。
- 跳过普通绘制的容器仍检查自定义 `dispatchDraw` 和 overlay，避免漏采装饰画面；读取失败不当作透明层压缩。
- 保留窗口根身份、二进制完整性、截图尺寸和前台窗口校验，以及补采数量、像素、时间上限和资源清理；部分失败仍保留已取得的图片。
- 原生 View 采集先显示树和整屏预览，再补独立图；采集中可选择、折叠和旋转，取消后丢弃未完成预览。已命中 DDMS 图片的系统普通 View 跳过重复补图查找，特殊/自定义控件仍检查。
- 原生 Debug View 和 SDK 混合快照均可刷新单控件或小分支，不重抓整包。分支内新增、删除、重排按对象身份更新；分支外、进程或窗口变化时拒绝，失败层只在身份和尺寸仍匹配时保留旧画面。单次最多 64 个可见控件；历史快照及 Qt/QML 暂无此入口。
- 快速连点刷新现在只发一个请求；刷新中取消或切换 App 会拒绝旧结果并清理 JDWP 转发。

## 已知限制

- Release App 不支持；仅包名带 `debug` 不算调试包，必须允许 `run-as`。
- Compose、Flutter、WebView 内部绘制树尚未接入。
- SurfaceView、OpenGL 外部缓冲受系统版本、厂商接口和保护标记限制；不绕过 DRM，不使用整窗截图冒充独立缓冲。
- V2 未暴露控件绕 X/Y 轴旋转后的完整矩阵，这类节点及后代暂不猜测屏幕坐标；二维缩放、旋转、平移和父级滚动已有解析回归。
- QML 复杂自绘、任意变换、部分圆角裁剪和未暴露的绘制顺序不能保证逐像素一致。
- 控件树、屏幕截图和独立图层不是同一帧原子快照；视频、动画页面可能存在时间差。
- 局部刷新只更新请求范围内的层，不把整页同步到同一帧；动态控件在补图期间移动会保留旧画面并提示重试。分支超过 64 个可见控件需选较小分支或整页重采。
- 完整采集耗时随页面变化：旧 DDMS 1170 节点页约 36 秒；近期 SDK 业务稳态页约 25–30 秒，两次冷启动约 37 秒。不同页面状态不能直接比较；树/整屏可先操作，新版 SDK 可分段预览独立图，但业务 App 连续采集仍有失败轮。
- 业务 App 在连续采集后出现过自身慢态、MIUI 记录挂起及 dump EPIPE 循环（需 `am force-stop` 重启才能恢复）；在已慢的 App 上中断一次 dumpsys 读取可能使其升级为逃逸循环，中断源未逐项定责（工具超时终止、进程清理或系统 dump 超时）。就绪循环的读取下限已实施（剩余不足 1.5 秒不再发起读取）；楔死检测提示待评估。
- 取消 DDMS 抓图不会立刻停止 Android 进程内已开始的工作；立即重采可能先等待约 20 秒，再执行新一轮抓图。完整采集、单控件和小分支刷新时的物理拔线均已在 Android 14 当前机型验证；其他时点和设备未覆盖。
- Android 10–13、更多厂商机型、Windows 系统 DPI、多显示器和干净系统安装仍需真实环境验证。
- Lookin 式 Debug SDK 的 P0 样例已在 Android 14 真机验证：进程内可取得整组图、透明叶子图和父控件自身图；父图没有红色文字或不透明绿色子项，但保留父控件自己的黄色装饰，越界子项被裁剪，动态尺寸变化后仍隔离。Debug Provider 可按对象取图并返回摘要；Release 无 SDK。业务 Debug App 已通过可选依赖接入并完成上述混合采集；完整采集已按条件采用 SDK 可见层图，JDWP 保留局部刷新和缺图/特殊缓冲补采。样例与业务首页的成功不代表所有自绘类型都能取得独立图；跨时刻身份或几何超限仍安全回退。
- ReClipMac 的 Android Dev 包属于 Qt/QML：原生 View SDK 只能读取 Qt 宿主节点。Qt 专项通道已取得对象树、叶子独立图、已暴露样式和折叠父项整组图，不需改装业务 APK。展开后的复杂自绘父项仍只有自身已暴露样式或边框；Qt 公开抓图 API 不提供通用的“父项自身像素且排除子项”能力。动态页已测；视频页在此 App 中不存在，其他图形后端尚未验收。
