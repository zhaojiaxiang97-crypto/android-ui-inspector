# 3D 全量层级总览改造计划

状态：已实施
日期：2026-09-14

## 1. 目标

截图完成后，直接把整棵可见 UI hierarchy 的所有子节点放进同一个 3D 层栈。用户不需要先点击某个容器才看到它的子节点。

```text
Root（只作最底层参考边界）
 ├─ Child A
 │   └─ A-1
 ├─ Child B
 └─ Child C
     └─ C-1
```

- 所有可见后代一次性沿 Z 轴展开；
- 点击树或画布中的节点，只改变绿色选中态、蓝色悬停态和属性面板；
- 选择容器不会切换到局部子窗口栈，也不会重排其他层；
- Root 只画淡边界，不作为一张覆盖其他控件的重复截图。

## 2. 层级顺序

同一父节点按以下顺序放入层栈：

1. `drawing-order`；
2. `index`；
3. XML 出现顺序。

层栈按树结构深度优先展开：父节点在其后代之前，同级节点保持上述顺序。选中状态不参与 Z 计算，因此切换选中项不会让整个场景跳动。

## 3. 视觉与交互

| 元素 | 表现 |
| --- | --- |
| 有自身样式的控件 | 显示其自身截图区域 |
| 结构容器、无自身样式的控件 | 只显示轮廓 |
| 选中控件 | 绿色高亮，不置顶 |
| 悬停控件 | 蓝色高亮，不置顶 |
| 截图底图 | 低透明度空间参照，不可点击 |
| Root | 最底层边界，不可点击 |

层数超过 24 时，仅压缩相邻层的 Z 间距，保持整体深度处于稳定相机范围；正常真机截图最多渲染 512 个可见层，并在画布元数据中标记截断状态。

## 4. 实施点

- `buildLayerOverview` 收集全部可见后代，构建稳定的全量 Z 栈；
- `Layer3DPreview` 始终渲染该总览，不再接收“当前展开容器”；
- `ScreenshotPreview` 截图加载完成后直接进入 3D 全量展开；
- 左侧树的展开状态与 3D 总览共用：收起父节点会收起整条子树，右侧不再渲染其后代；
- 树选择、画布点击和属性面板继续共享同一个选中节点；
- 单测覆盖：嵌套节点会在首次总览出现，且选中不同节点时 Z 坐标不变。

## 5. 验收

| 场景 | 预期结果 |
| --- | --- |
| 截图完成 | 全部可见子节点立刻展开 |
| 收起左树父节点 | 该节点的全部后代从右侧 3D 总览收起 |
| 选择容器 | 总层数与所有节点的 Z 坐标保持不变 |
| 选择叶子控件 | 仅更新绿色高亮和属性 |
| 鼠标划过控件 | 显示蓝色高亮 |
| 旋转、缩放、平移 | 底图、全部层和高亮同步移动 |
