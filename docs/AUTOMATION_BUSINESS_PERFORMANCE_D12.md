# D12：检查点优化的完整业务交叉对照

更新：2026-10-17。状态：八轮测试与归档检查完成。

## 结论

D11 在本次固定业务中的完整墙钟中位数从 **60.240 秒降到 56.726 秒，减少 5.83%**；产品步骤耗时中位数从 **53.686 秒降到 51.191 秒，减少 4.65%**。保留 D11，但这组小样本仍不能证明长期稳定收益，20% 整段目标未达到。

八轮全部完成，40 次确认输入、0 次未知输入，72 份必要归档均通过重新导入。各轮包含原始采集失败、自动重读及同请求只读恢复；“整轮成功”不代表底层采集从未失败。双帧、来源、授权、期限和停止边界保持原规则。

本轮只增加对照工具和记录，没有修改生产逻辑或更新 Helper。D11 的 177 项测试、类型检查和完整构建是上一轮验证结果，本轮不重复计数。

## 对照方法

- A：D11 前保存的 D9 实现和旧回测脚本；B：D11 实现和新脚本。
- 从当前源码共同快照 `7c65ef85e1fd96a73dbcf9d0d94a6b6a702970d9` 创建独立基线工作树，仅回退 D11 的五个源码文件，其余生产源码一致。构建后的基线与冻结版本仅依赖路径注释不同，执行内容相同。
- 同一手机、同一 Helper、同一 App、同一业务选择器和条件；每轮独立会话，先进行两次只读预热。
- 每轮任务为“播放起点 → 返回 → 我 → 收藏 → 严格确认末端 → 最后有效视频 → 播放状态新双帧确认”。
- 先 A1/B1/B2/A2；四轮全部通过、两对墙钟及产品耗时均更低、两项中位收益均至少 5% 才扩大。试跑收益为 10.49% / 10.12%，按预先记录的门槛追加 A3/B3/B4/A4，随后结束。
- 完整墙钟取回测器的 `summary.wallMs`，含流程中的命令往返和逐步冻结归档，不含软件切换、授权和预热。产品耗时按唯一产品步骤去重。两者不能相加。
- 所有慢样本均保留，没有换选择器、补发输入或删除失败来提高结果。

## 为什么整段收益比局部小

D11 只减少起点、终点检查点的重复采集。普通完整流程从 25 次观察降为 23 次；点击、返回、滚动及其复核仍占大部分时间。

| 步骤墙钟中位数 | A | B |
| --- | ---: | ---: |
| 起点检查 | 6.659 | 4.989 |
| 返回 | 10.522 | 10.386 |
| 进入我 | 8.276 | 8.282 |
| 进入收藏 | 7.204 | 7.737 |
| 确认列表末端 | 7.762 | 7.955 |
| 打开最后视频及恢复 | 10.890 | 11.299 |
| 终点检查 | 8.499 | 5.243 |

各步骤中位数不能相加推算整段中位数。检查点确实更快，但其他步骤的波动抵消部分节省。

B 的响应头等待累计中位数为 29.336 秒；有合法设备计时的读取中，树读取累计中位数为 13.155 秒、PNG 编码为 7.753 秒。这些属于嵌套计时，不能相加，也不能把响应头等待全部归因于某一项。

## 证据检查

- 72 份报告逐份重新导入，树、截图、附件及步骤均完整；唯一产品步骤也为 72，重复引用没有重复计时。
- 所有 partial 检查点均保留两个不同快照，第一帧时间不早于该 wait 开始；B 显式选择 Helper 后端。
- A 每轮十份、B 每轮八份归档，是消除两个独立 capture 步骤的结果，必要证据没有减少。
- 八轮共 194 次观察；10 次 Helper 自动恢复读取、14 次其他自动恢复读取、8 次独立只读恢复均计入耗时。
- 每轮 3 个“未产出观察”位置来自原失败阶段，共 24 个；与已存在附件缺失区分统计，缺树、缺图和无效附件均为零。
- 每轮结束均确认停止本次会话；已恢复原目录的 D11 软件供继续使用。
